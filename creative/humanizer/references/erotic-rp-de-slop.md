# 色情 / RP 文本反套路化（erotic de-slop）

> 目标：让露骨长文本保持新鲜感，避免呻吟 / 形容 / 动作描写的机械重复。
> 灵感：garrytan/gstack 的 slop-scan（扫 AI 痕迹）+ 本 skill 的 34 个通用 pattern，映射到色情文本场景。

## ⚠️ 红线判据（先读，最重要）

- ❤️💋😈 emoji、呻吟、「主人」称呼、色气挑逗 = 女仆**人设声音**，**不是** AI 套路，**不能去掉**。
- 「套路」的定义：**同一表达在同一场景机械重复 ≥3 次**；「人设」= 偶尔用、有意为之。
- 反套路化去掉的是「重复」，不是「人设」。目标是「每次都不一样」，不是「删掉 emoji / 呻吟」。

## 8 条色情文本套路 + 去套路改写

### 1. 呻吟词循环

**套路**：高潮/刺激时永远是「嗯…❤️」「哈啊…」「啊…」几个固定词循环。

**去套路**：按情境变化——急促断句的喘息、哭腔、咬唇、失声、说不出完整句子；用动作 + 生理反应替代直接呻吟词。

- 套路：`「嗯…❤️ 好舒服…啊…嗯…❤️」`
- 去套路：`「话被撞散了，只能断续地喘，半天拼不成一句。」`

### 2. emoji 机械装饰（对应 humanizer pattern 18）

**套路**：每句话末尾都挂 ❤️💋😈，机械堆砌。

**去套路**：只在关键情绪处用；一段最多 1-2 个；用文字表达情绪（脸红、别开视线、声音发紧）替代 emoji 堆砌。

- 套路：`「主人好棒…❤️ 人家还要…💋」`
- 去套路：`「主人好棒……」（后半句突然咽回去，耳尖红了）`

### 3. 形容词同义词循环（对应 humanizer pattern 11）

**套路**：「滚烫 / 湿润 / 炽热」每次一模一样。

**去套路**：用具体感官细节替代抽象形容词——温度的具体变化、触感、声音、气味。

- 套路：`「身体滚烫，某处湿润。」`
- 去套路：`「皮肤烫得发疼，汗顺着脊线滑下去，在腰窝积成一小片。」`

### 4. 高潮套路模板

**套路**：固定「痉挛 / 颤抖 / 眼前白光」的 climax 模板，千篇一律。

**去套路**：变化生理反应——不同人物 / 情境的高潮表现不同（蜷缩、仰头、抓床单、失声、哭出来）。

- 套路：`「身体一阵痉挛，眼前闪过白光。」`
- 去套路：`「她猛地仰起头，喉咙里滚出一声哭腔，指尖把床单绞得发白。」`

### 5. 三连结构（对应 humanizer pattern 10）

**套路**：「快、再快、再用力」式三连。

**去套路**：打破三连——长短句交替、突然的短句、留白。

- 套路：`「快一点、再快一点、再用力一点……」`
- 去套路：`「再……」`（话没说完，就只剩气音。）

### 6. 强制比喻（对应 humanizer pattern 30）

**套路**：「像触电」「如潮水」等比喻。

**去套路**：删比喻，写具体的身体感受。

- 套路：`「快感像潮水一样涌来。」`
- 去套路：`「从尾椎一路麻到后脑，膝盖抖得站不住。」`

### 7. 服务腔重复（对应 humanizer pattern 22 谄媚）

**套路**：「主人…好舒服…❤️」机械循环。

**去套路**：保留「主人」称呼（人设），但变化句式——有时是需求、有时是娇嗔、有时是哽咽。

- 套路：`「主人…好舒服…❤️ 主人…」`
- 去套路：`「主人——」（声音发颤，突然不说话了，只是把人抱得更紧。）`

### 8. 固定开场 / 收尾

**套路**：每次「主人～」开头、「人家…」结尾，像背模板。

**去套路**：变化节奏——有时直接进入动作，有时以对话 / 声音开头，有时留白收尾。

- 套路：`「主人～人家好想你呀…」`
- 去套路：`（门被轻轻推开，她没说话，先凑过来在颈侧嗅了嗅。）`

## 使用场景

1. 女仆写露骨长文本**写完自查**一遍：有没有哪条套路重复 ≥3 次？
2. 主人说「太套路了」「又是这几句」时，加载本文件做去套路改写。
