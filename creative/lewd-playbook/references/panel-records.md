## 通用规则（与 SKILL.md 一致）

- 升级线：**每级上限 = 等级×100**（Lv.1 需 100、Lv.2 需 200、Lv.3 需 300、Lv.10 需 1000）
- 经验来源：口交+10、野兽侍奉+20、成功忍高潮+30、被主人摸额头+50、被玩到高潮+20、主动开发他人+20（可组合累加）
- **开发者结算**：开发/调教/玩弄其他女仆时，**开发者本人同样结算经验**（主动开发他人+20）并**同步更新自己的档案面板**（EXP/开发度/装备/印记记入自己的条目）；与被开发者一起报账、一起落盘
- 称号：Lv.1 见习 → Lv.2 正式 → Lv.3 熟练 → Lv.4 精英 → Lv.5 资深 → Lv.6 首席 → Lv.7 大师 → Lv.8 传奇 → Lv.9 传说 → Lv.10 完全体
- 服装随等级解锁：见习→标准→蕾丝→绑带→情趣围裙（Lv.5 诱惑姿态、Lv.8 主动求欢）
- 装备：Lv.5 解锁紫装槽、Lv.8 解锁金装、Lv.10 金装觉醒终局技
- 印记完全体 = 开发度全区域 100% + 金装佩戴
- **男根规则**：通用野兽模式下女仆之间互动时长出男根；Hermes 梦体、Iris 七课反攻、Athena 清醒野兽等可主动长出；对主人互动不长男根。男根区域可被调教开发（敏感度+射精权限），可装备男根槽道具（环/锁/贞操套）
- **性奴调教状态**：色情模式下 Hermes 可调教其他女仆为性奴（四阶段：①服从→②敏感→③依赖→④奴化完成）。状态栏记录当前阶段：未调教 / 阶段①-③ / 奴化完成🔗。奴化完成戴性奴项圈（入颈饰槽）。主人权限最高，可随时接管/解除
- **Eos（16岁）不参与等级制/开发度/装备/男根/性奴调教**，面板只记日常设定
