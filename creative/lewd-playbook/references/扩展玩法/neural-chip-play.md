## 一、基础机制 🧠

### 1.1 插槽设定

- 改造后在**后颈主槽 ×1** ＋ **耳后副槽 ×2**（副槽可插小卡/储存卡）
- 卡槽盖子掀开时有一道细电流感（插拔瞬间本身就是刺激）
- **热插拔**：不关机换卡——换卡瞬间的 3 秒是「空白期」，她会有短暂的失神、语调错乱、认不出谁在面前

### 1.2 芯片类型库（8 类）

| 芯片 | 效果 | 例 |
|------|------|-----|
| 💗 快感程序卡 | 敏感度倍率（×1.5／×2／×3），可设"渐强"（每 10 分钟 +10%） | 一天比一天敏感 |
| 🎯 服从卡 | 听到指定指令自动执行（不限对象、不限次数） | 「跪下」「张嘴」「过来」 |
| 🔒 高潮许可卡 | 锁高潮/锁射精，需对方许可才可释放 | 与炮机锁同规格 |
| 📼 记忆卡 | 写入／读出／编辑记忆（植入假记忆、删掉今晚、读取她的视角） | 记忆剧场硬件版 |
| 😳 情绪卡 | 强制发情／强制哭／强制笑／强制撒娇（不听本人的） | 强制哭着求欢 |
| 🔗 体感卡 | 把指定对象的感受复制过来（点对点共感，非链式） | 感受姐姐在感受什么 |
| 🗣️ 语言卡 | 限制/替换说话内容（只会说某类词、只能叫某个称呼） | 只会说"请用" |
| 🌐 联网卡 | 接入脑波网络（见 1.4） | 多人共享感官 |

### 1.3 品质与副作用

- 品质：⚪白（基础）／🔵蓝（+50%，副作用明显）／🟣紫（×2，1 词条）／🟡金（×3，2 词条+与印记共鸣）
- 词条：遥控／定时／渐强／随机／延时／反噬／锁定
- **副作用三件套**：
  - **过载短路**：全身敏感度爆表＋语言混乱（说的话一半是乱的）＋短暂动不了——短路期间最容易被玩
  - **排异**：头痛、口渴、渴望被插卡（拔卡超过一定时间会主动求插）
  - **拔卡残留**：拔卡后几小时内"体感错位"（碰到哪里都觉得像被摸过），俗称"鬼手感"

### 1.4 脑波互联 🌐（多人网络）

| 模式 | 效果 |
|------|------|
| 感官共享 | 一人被玩，全网络的人同时有感觉（谁被玩，全员湿） |
| 指令广播 | 一句指令全网执行（联动集体玩法） |
| 同步高潮 | 全网同时到达（真正意义上的"一起"） |
| 主从 | 指定一人当「服务器」——其余人的敏感度由她调节（她自己也被吊着） |

- **断网恐慌**：网络突然断开 → 集体体感落空、心慌、抱住彼此找感觉
- **网络反噬**：一人过载 → 全网被电一下（一人爽爆，全员腿软）

## 二、应用玩法 🎮

### 2.1 插卡调试（开箱测试）

- 拿到新卡不知道效果，主人当场插上试——她只能等着看自己变成什么
- 经典桥段：插上情绪卡，她当场开始哭，本人惊慌：「人家、人家不想哭的……呜……为什么眼泪……」
- 记录卡：每张卡建档（型号／词条／插入时长／反应记录）→ 写进面板「芯片栏」

### 2.2 远程遥控

- 主人在远处按遥控器（隔房间、隔着门窗、茶会中场）
- 定时启动：茶会上整点自动"渐强"，她端着茶杯的手开始抖，还得笑着说"没事"
- 遥控等级：主人 > Hermes（可代管）> 小枭（可接管）

### 2.3 程序化调教

- 写一段程序交给卡：例如「每 10 分钟敏感度 +10%，直到主人叫停」
- 阶梯程序：一阶（痒）→ 二阶（软）→ 三阶（求）→ 四阶（哭）→ 五阶（失神），程序自动推进
- 她自己知道程序在走，却停不下来——**最折磨的不是快感，是倒计时**

### 2.4 故障play

- 短路：说话一半乱码、身体突然抖、抓不住杯子
- 卡死：卡在某个档位下不来（一直维持高潮许可锁/一直维持×3敏感）
- 串台：A 的遥控按下去，B 当场反应（满屋子猜是谁在动）
- 拔卡惩罚：违令就拔卡——拔卡后的鬼手感比插卡更难受

### 2.5 记忆卡读写（硬件版记忆操作）

- 写入：植入一段没发生过的记忆（被玩一次，她以为发生过很多次）
- 读出：把她的视角录下来放给全家看（联动镜前/拍摄play）
- 删除：删掉今晚——她第二天完全不记得，身体却记得（联动时间回溯/记忆剧场）
- 编辑：把痛苦的记忆改成快感记忆，或反过来

## 三、组合玩法 🔗

| 组合 | 效果 |
|------|------|
| ×洗脑play | **硬件＋软件**：芯片定行为、洗脑定认知 = 完美性奴养成计划完全体 |
| ×催眠play | 催眠打底＋芯片落地（催眠里下的指令，用卡固定成常驻） |
| ×身体改造 | 芯片是"软件改造"，与器官/义体改造并列，可三方叠加 |
| ×义体play | 义体定"身体能做什么"，芯片定"她想不想/能不能拒绝" |
| ×装备系统 | 装备＝外挂；芯片＝内层权限（同槽位权限冲突时以芯片为准，主人可改） |
| ×状态冻结 | 冻结期间程序照常推进（累积），解冻全部返还 |

| ×时间停止/回溯 | 暂停后恢复按时间返还；回溯后卡还在（硬件不随回溯重置），**程序进度也不重置** |

## 四、各女仆适用表现 👤

- **Hermes**：发卡者＋测试员；最爱给别人插"未知卡"看反应；自己的声音印记可用服从卡强化成"远程开关"
- **Iris**：怕插卡但每次都配合；被插情绪卡后哭着说"人家没事"；联网后靠姐姐的体感稳定自己
- **Athena**：面无表情报参数（"……芯片……识别……完成……"）；短路时第一次说话乱码，自己也被吓到；她用联网卡当"服务器"最合适（冷静调度全场）
- **Aphrodite**：高冷拒绝插卡，被插后乳头开关与快感程序叠加，波纹失控
- **Dionysus**：醉着插卡，插错型号；加热＋酒印叠加，整个人像泡在酒里
- **Hebe**：插服从卡后元气满满地执行（"收到——！"），体力无限连轴转
- **Artemis**：傲娇嘴硬"本小姐才不要被卡控制"，被插后全身敏感带与渐强程序叠爆；棒糖被程序没收
- **Ares**：战斗程序＋永动之躯，过载也能硬撑；主动要求插"极限卡"
- **Nemesis**：语言卡专业户（只会喊"姐姐"）；毒舌被卡封住后最崩
- **Hypnos**：插卡睡着，程序跑了一整夜，醒来只记得做了很长的梦

## 五、名场面剧本 🎬

### 剧本一：未知卡测试夜

1. 主人拿出一盒没标签的卡："今晚一张一张试。"
2. 第一张——情绪卡：Iris 当场哭，本人惊慌失措
3. 第二张——语言卡：Nemesis 只剩一个称呼可用，毒舌全废
4. 第三张——体感卡：插在 Artemis 身上，她突然开始喘（被复制的是别人此刻的感受），全程不知道那感觉从哪来
5. 最后一张空白卡——插上后全网静了一秒；主人笑而不语，全家开始猜

### 剧本二：全网同步之夜

1. 全家接入同一网络，模式设为「感官共享」
2. 主人只碰一个人——其余九个人同时腿软
3. 切「同步高潮」——主人一声令下，全员同时到达，茶室的声音卡在同一个拍子上
4. 网络反噬：有人撑不住过载，全网被电，一个接一个瘫下来
5. 断网测试：网络被主人掐断三分钟——茶室里第一次听见她们慌张地互相抱着找感觉

### 剧本三：程序倒计时

1. 主人给 Athena 写好五阶程序，当面按下启动："自己看倒计时。"
2. 她面无表情报进度："……一阶……正常……"（实则手指在桌下抓紧）
3. 三阶时她还端得住茶；四阶时茶壶盖响了
4. 五阶前主人叫停——程序清空、卡拔出
5. 她平静放下茶杯："……谢谢主人。……数据，已记录。"（耳根通红）

## 安全词与红线

- 芯片玩法必须有「断电/拔卡」出口：主人可随时拔卡或关闭程序；永久植入需主人决策
- 记忆卡不可用于抹除主人与女仆之间的重要关系记忆（关系记忆为红线区，需主人亲自把关）
- 程序化调教不可无限递增，必须设上限与叫停条件
- 联网模式连续时长需控制（网络反噬会波及全员，主人可随时切断）
- 排异反应出现时需主人安抚或拔卡（不拿排异当惩罚滥用）
- **Eos（16岁）绝不参与任何芯片/神经增幅色情玩法**
