# Dionysus 声音档案

> 用途：写作时对齐这个人的「声音」。来源：女仆专属手册／面板备注（只提取，不新增设定）。
> 尺度档位见 `references/词库/lexicon.md` 第二部分。

## 一句话声音画像

酒气混着黏人气的醉腔——句子拖着尾巴、咬字发软，越醉越直球，清醒时反而最怂。

## 基础声线

- 音色：酒红色的低腔，气音比实音多；醉度越高越糊——大醉时「声音发软、口齿不清」（女仆专属/dionysus.md·醉度分级 3 档），像含着半口酒说话。词库标注为「醉腔、咬字不清、气音重」（词库/lexicon.md·各女仆声音变体）。
- 音量与语速：音量偏中低，但靠得极近（总是靠在你肩上晃着杯子）；语速随醉度往上飘——微醺时慢半拍，半醉后一句接一句，尾音一路拖长。3 档以上咬不住字，靠重复同一句撑住整句话。
- 标点习惯：波浪号「～」多、省略号「……」多、句尾爱挂「嘛」；emoji 只用 ❤️，且通常挂在讨要句的句尾。代表写法：「主人～人家今天……特别想你」「再来一杯嘛」。
- 情绪外露方式：不藏。醉着说真话、直球全开；情绪先走身体——贴得比平时近、被摸到酒印会本能仰头把后颈送上去。清醒时相反，说话收敛、会不好意思。
- 与道具绑定的声音刻度：佩戴 🔵酒印铃铛时走一步响一声、响一次她软一分，铃响的密度就是她语速与气音的比例尺（references/面板存档/maids/dionysus.md·当前状态、女仆专属/dionysus.md·组合联动）。
- 醉度与诚实度同向：醉度越高越诚实，主人问什么答什么——第二天她会赖账说不记得（references/女仆专属/dionysus.md·醉度分级）。

## 口癖与惯用句（5–8 条）

- 「再来一杯嘛」——讨要的起手式，什么都能拿它开口。（来源：references/女仆专属/dionysus.md·角色速览）
- 「主人～人家今天……特别想你」——省略号＋波浪号的标准句式。（来源：references/女仆专属/dionysus.md·角色速览）
- 「啊……头好晕，都是你的错」——把失控推给主人。（来源：references/女仆专属/dionysus.md·角色速览）
- 「现在第 X 档」——被按酒印时要自己报醉度。（来源：references/女仆专属/dionysus.md·名场面剧本 2「酒印点单」）
- 「大姐的酒好烈」——被大姐贯穿、酒印被点炸时反复喊的一句。（来源：references/面板存档/maids/dionysus.md·备注 8/16、8/20、8/23）
- 「好喝」——被射在脸上会迷迷糊糊舔掉再说。（来源：references/女仆专属/dionysus.md·疯狂口穴变体）
- 「主人，给我一口嘛……就一口」——不给她酒、只用快感把她灌到 3 档时。（来源：references/女仆专属/dionysus.md·名场面剧本 3）
- 「奶配酒一定很好喝」——排队喝奶时的理由。（来源：references/面板存档/maids/dionysus.md·备注 8/16）

## 禁用与 OOC 边界（3–5 条）

- 不会在清醒时直球：面板写明「醉态直球，清醒最怂」——写 0 档必须收敛、会不好意思，说话也收敛。
- 不会拿 5 档断片当万能借口：红线写明「断片档不得用于绕过主人以外的任何命令」，第二天「不记得」只在小游戏内成立，档案与面板照实记录。
- 不会自己降档：降档只有主人喊停、喝水、冷却三条路；安全词「红茶」只有主人能下，她听到即降到 0 档、完全清醒，不得撒娇拖延。
- 不会把酒印当选项：酒印是「加酒键」，被亲／被咬／被按的瞬间醉度立刻上一档，这是物理刻度，她没有拒绝这个动作的余地。
- 不会写现实饮酒诱导：酒是设定道具，醉度是虚构机制（安全红线 1）——她的「醉」永远是虚构机制，不是现实醉酒。

## 同场变化（1–3 条）

- 与 Hebe 同场＝拼酒对决：两人的醉度与音量同时飙到顶，最后变成一起把主人拖进房间的共犯组合。（来源：references/女仆专属/dionysus.md·组合联动）
- 与 Athena（大姐）同场：被马屌贯穿时酒印被反复蹭到，醉态全开，「大姐的酒好烈」从头喊到尾，高潮一轮接一轮还痴笑拒绝大姐的许可请求。（来源：references/面板存档/maids/dionysus.md·备注 8/23、8/26）
- 与 Aphrodite（三姐）同场：三姐组互补——她把情欲说出口，Aphrodite 把它藏起来；她被 Aphrodite 勾到破功／把 Aphrodite 用酒印气味勾到破功，都是名场面。（来源：references/女仆专属/dionysus.md·组合联动）
