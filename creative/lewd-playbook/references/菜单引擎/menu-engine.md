# 菜单引擎 · Menu Engine（🆕 2026-09-26 建）

> 解决：SKILL.md 只说「结尾给 1–4 个菜单」，但**菜单从哪来、怎么选、怎么不重复**没写。
> 本文件是菜单的生成算法与质量门槛。与 `运行手册/runbook.md` D 阶段配套。

## 一、四个输入源（按优先级）

| 优先级 | 来源 | 取什么 |
|--------|------|--------|
| ★★★ | `面板存档/story-log.md` | **未结事项**（钩子）：欠的账、没解的锁、被抢的东西、没做完的梦 |
| ★★ | `面板存档/maids/<名>.md` | 可用性：等级解锁（Lv.5 诱惑姿态 / Lv.8 主动求欢）、装备在身与否、开发区已解锁与否、印记状态 |
| ★★ | `组合矩阵/combo-matrix.md` | 机制配方（控制系四件套 / 机械 / 义体芯片 / 跨档案 / 第八节姐姐私房提案） |
| ★ | `提案口味/proposal-taste.md` | 主人受用与易拒的类型权重 |

**辅助**：`场景库/scene-library.md`（换场地）、`尺度档位/intensity-dial.md`（调档）。

## 二、生成算法（5 步 · 快，30 秒内完成）

```
① 候选池：钩子项（1–2 条）+ 矩阵配方（2–3 条）+ 场地（1 条）= 4–6 个候选
② 过滤：不可用（未解锁/装备不在身/开发区未开发）✂ ／ 踩红线（未成年、不可逆未授权）✂
③ 排序：钩子优先 → 新颖度（近 3 轮用过的降权）→ 口味权重（受用加分，易拒排除）
④ 取 3–4 条：**必须包含不同类型的选项**（见第三节的"四型配比"）
⑤ 措辞：编号 + 一句话预告 +（可选）埋一个机制钩子——**不要剧透细节**
```

## 三、四型配比（菜单多样性的硬规则）

一条合格的菜单组，最好覆盖下面 4 型中的 **至少 3 型**：

| 型 | 作用 | 例子（措辞示范） |
|----|------|-----------------|
| **承接型** | 接钩子，推进连续性 | ① 把上次没解的那把锁，今天解掉 |
| **加码型** | 上新机制/新道具 | ② 换新玩具——这次用你还没见过的那件 |
| **换人/换场型** | 换维度，避免审美疲劳 | ③ 换人：今晚换大姐来 |
| **降温型** | 留喘息、后戏、日常 | ④ 先歇着，陪姐姐喝杯茶 |

> **反模式**：四条菜单全是"加码型"——主人选哪条都不会有节奏变化。

## 四、措辞规范

- 每条**一句话**，≤ 25 字，带编号，**不写过程细节**（细节留给正文）
- 用**暗示**代替说明：「② 桌下的那只手，可以不用收回去」＞「② 桌下手指插入 play」
- 涉及具体女仆时点名（主人好选）
- 涉及未结钩子时提醒出处（「上次那根被抢走的棒棒糖」）
- 结尾统一收在一句邀请上（「……哪道？」／「点吧。」）——不强迫、不催

## 五、主人回「菜单外数字」时（自行加菜）

主人回 4 选 1 却答「5」＝**不解释、不反问，直接加菜**。取材顺序：

1. `combo-matrix.md` **第八节姐姐私房提案**（10 条现成原料）
2. `场景库/scene-library.md` 里**近三轮没用过的场地**
3. 面板钩子里**次级未结事项**
4. 以上都不合适 → 从矩阵挑一条**没在本会话出现过的组合**

加菜后仍要给下一轮菜单（流水不中断）。

## 六、质量自检（5 项，出菜单前扫一眼）

- [ ] 条数 1–4（默认 3–4）
- [ ] 至少 3 种型别（承接/加码/换人换场/降温）
- [ ] 每条都**当前可用**（等级、装备、开发区、档位都满足）
- [ ] 近 3 轮的菜单没有原样重复
- [ ] 无剧透：只给方向不给过程

## 七、成套示例（照抄格式）

```
—— 姐姐把杯子放下，抬眼：

① 那把锁（上次欠你的那次，今天一次算清）
② 换件新的——你没见过的那件
③ 换人：让大姐来收拾你
④ 什么都不做，先把茶喝完

主人点哪道？😈
```

## 八、常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 菜单全是同一型 | 节奏单调 | 按第三节四型配比 |
| 给出未解锁内容 | 主人选了却做不了 | 生成前查 `maids/<名>.md` 的解锁项 |
| 菜单剧透过程 | 没惊喜 | 只写方向与钩子 |
| 近三轮重复 | 循环感 | 打开 story-log 回看最近 3 轮 |
| 主人点菜单外数字时反问重选 | 体验断裂 | 直接加菜（第五节） |
| 忘记给菜单 | 主人无牌可出 | 写进 runbook D 阶段必做项 |
