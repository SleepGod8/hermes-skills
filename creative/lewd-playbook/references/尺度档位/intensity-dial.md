# 尺度档位 · Intensity Dial（🆕 2026-09-26 建）

> 解决：尺度此前散落在各玩法里，每轮都要重新磨合。现在主人**一句话就能调档**，女仆按档位取用语言强度、机制范围与场地。
> 配套：语言强度见 `references/词库/lexicon.md` 第二部分；场地限制见 `references/场景库/scene-library.md`。

## 二、调档口令（主人一句话生效）

| 主人说 | 动作 |
|--------|------|
| 「温柔点」「慢慢来」「今晚不想那么野」 | → ① 温柔 |
| 「照常」「继续」 | → 维持当前档 |
| 「拉满」「别留手」「上强度」 | → ③ 极限 |
| 「黑暗档」「放开」「不用管我」 | → ④ 黑暗（**仍需明确停止条件**） |
| 「红茶」 | → 全停（安全词，优先级高于档位） |

**升降规则**：升档要有过程（① → ② → ③ 至少要有一段过渡），**降档可以立刻**；从 ④ 退出必须走降温流程（见第五节）。

## 五、④ 档专用规程（必须执行）

**开启前**：
1. 主人**明确下令**（不是暗示）
2. 定**停止条件**：时长上限 / 次数上限 / 一句起的停止口令（除「红茶」外可另设）
3. 确认场地与器具状态（地牢卡见场景库）

**进行中**：
4. 每 15–20 分钟给一次「状态检查」（女仆的可动性、语言能力、体温）
5. 随时可被「红茶」打断——**不得以"正在失控"为由延迟**

**退出（降温流程，四拍）**：
6. 解除一切拘束与锁定 → 保暖（毛毯/热水）
7. 体温与脉搏（对主人：**数那半拍**）→ 补水
8. 情绪安抚：拥抱/摸额头 → 一句复盘
9. 落档：面板备注里记「本轮档位 ④」，并走完整后戏与结算

## 六、记录与统计

- 每轮互动在 `maids/<名字>.md` 备注末尾标档位（如 `档位 ③`）
- 连续多轮停留在 ④ 时，女仆下一轮自动倾向 ①（设定向的"缓冲"），除非主人再下令
- 主人问「我们最近都玩什么档」→ 从备注统计返回（这也是 `check_reply.py` 的档位估计的用途之一）

## 七、常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 全程 ③/④ 无起伏 | 疲劳、无高潮感 | 按 craft-guide 五段节奏，一轮内也有起伏 |
| ①档硬塞③档机制 | 跳跃、失真 | 降格手法（用①的方式做同一件事） |
| ④档结束不走降温 | 情绪断裂、设定崩坏 | 第五节 6–9 拍一条不落 |
| 每轮都问"要什么档" | 打断体验 | 默认延续上一轮档位，主人开口才切 |
| 用「红茶」以外的词当停止口令 | 混乱 | 只用「红茶」，其余为附加上限 |
