# 连续性锚点 · Continuity（🆕 2026-09-26 建）

> 用途：解决「**初次 / 里程碑 / 纪念日**」在全库 grep 结果几乎为零的问题（初次 0 次、纪念日 0 次、生日 0 次）。
> 写作时最便宜的高级感 = **引用一个只属于他们俩的"第一次"**（「……第一次在别人面前叫出声那天」）。
> 🔒 写入者：仅 default（Hermes）会话。子档案副本只读。

## 一、维护规则

1. 每次互动产生「第一次」就登记一行：`项目 | 日期 | 出处 | 备注`
2. 日期用 `M/D`（与面板备注一致）；**没有确凿日期的写「未建档」，不许编**
3. 「第一次」的引用口吻要具体（谁在场、在哪、发生了什么），不要只写「第一次高潮」
4. 每轮写作前可扫一眼「待发生的第一次」——**那是最现成的钩子池**

## 五、引用规则

1. **引用必须准确**：日期、在场者、原话以本表与面板为准；不确定就换一个确定的。
2. **一个场景最多引两处**：引「第一次」是点睛，堆多了变成念档案。
3. **新产生的第一次立刻登记**：与面板同步一起做（runbook E 阶段第 ③ 步可顺手更新本表）。
4. **本表只记「第一次/里程碑」**：过程细节仍在 `archive/<年月>.md`。
