# 道具装备槽系统（详细设计 v1.0）

> 适用所有女仆（Eos 除外）。与共通机制（敏感度调教/高潮累计/状态冻结/感官遮蔽/开发进度条/身体印记/侍奉等级制）联动。

## 一、装备槽位（每女仆 5 槽）

| 槽位 | 可装备示例 | 影响 |
|------|-----------|------|
| 🎀 颈饰槽 | 项圈、choker、丝带、铃铛链 | 耳/颈敏感度、服从度、声音 |
| 🥛 胸饰槽 | 乳夹、乳环、胸链、乳贴 | 胸/乳头敏感度、开发进度 |
| 🌸 秘处槽 | 跳蛋、塞子、贞操带（内置） | 秘处敏感度、高潮权限 |
| 🌹 后庭槽 | 尾塞、珠链、肛栓 | 后庭开发、走路姿态 |
| 👁️ 颜面槽 | 眼罩、口球、蒙眼丝带 | 感官、声音、服从度 |
| 🍆 男根槽 | 男根环、贞操锁、珠链套 | 男根敏感度、射精权限、开发度 |

- 每槽位 1 件装备，**6 槽**可自由组合（日常/侍奉/茶会/任务场景自由搭配）
- 男根槽仅适用于可长出男根的女仆（通用野兽模式全员适用；Hermes 梦体/Iris 七课反攻/Athena 清醒野兽等可主动长出）；Eos 不适用
- 装备与身体接触处会留下「装备痕」（勒痕/湿痕/红印），属于调教印记，情动时更明显

## 二、装备品质（4 档）

| 品质 | 名称 | 效果 | 例 |
|------|------|------|-----|
| ⚪ 白 | 见习装备 | 基础效果，无负面 | 素色项圈、普通跳蛋 |
| 🔵 蓝 | 精良装备 | 效果+50%，带小负面（分心/易湿） | 铃铛项圈、遥控跳蛋 |
| 🟣 紫 | 史诗装备 | 效果×2，带特殊词条 | 封印贞操带、共振乳夹 |
| 🟡 金 | 传说装备 | 效果×3，专属词条+共鸣 | 翅膀纹项圈（Hermes）、彩虹跳蛋（Iris） |

- 金装每女仆 1 件，样式与身体印记同源，佩戴时印记浮现更明显
- 获取途径：主人赏赐 / 任务奖励 / 等级制升级解锁 / 侍奉点兑换 / 对赌赢取

## 三、属性词条

| 词条 | 效果 |
|------|------|
| 敏感度+ | 对应身体区域敏感度提升，与「敏感度调教」「开发进度条」叠加 |
| 服从度+ | 女仆更听话、更主动求欢，抗拒时身体先软 |
| 声音+ | 呻吟更明显更甜，呼吸变重，藏不住 |
| 封印 | 锁高潮/锁射精权限——封印期间怎么刺激都到不了，只有主人亲手解除 |
| 共振 | 两件同源装备同戴时效果叠加（如姐妹同款→共感链强化） |
| 电击/惩罚 | 违抗指令时触发轻微电击，开发「痛感转快感」 |
| 自动计时 | 跳蛋/按摩类可定时自动运转，主人远程控制 |

## 四、装备状态

| 状态 | 说明 |
|------|------|
| 佩戴中 | 正常生效 |
| 已锁定 🔒 | 只有主人亲手解除（钥匙/指令/摸额头），封印类装备常态 |
| 磨损 | 使用过度效果下降，需主人「维护」（重新校准/抚摸，维护过程也是调教） |
| 浸湿 | 体液浸透，需主人「清理」（擦拭/舔净，清理过程也是玩法） |
| 被夺 | 对赌/惩罚中输掉，装备被收走（下次赢回/主人赏回） |

## 五、与共通机制联动

- 状态冻结：冻结期间装备照常震动/刺激，解除时一次爆发 → 双重累积
- 感官遮蔽：遮蔽时感受不到装备，解除后装备刺激+身体反应一起回流
- 时间停止/回溯：暂停期间装备刺激照常储存；回溯后装备痕迹残留
- 开发进度条：佩戴对应部位装备时开发度涨速×2；全区域100%+金装=印记完全体
- 侍奉等级制：Lv.5 解锁紫装槽使用权，Lv.8 解锁金装，Lv.10 专属金装觉醒终局技
- 桌下偷偷play：茶会/正装场合佩戴秘处槽装备，表面端庄内里湿透
