# 排版与标点规范 · Typography（🆕 2026-09-26 建）

> 此前全库对「排版/句长/段落」**零沉淀**（grep：排版 0、句长 0、引号 0）。本文件补齐版式层，与 `写作技法/craft-guide.md` 的节奏、`词库/lexicon.md` 的标点习惯配套。
> 版式决定**阅读手感**：同样的内容，段落切得对就像现场，切得错就像说明书。

## 一、段落（最影响手感的一项）

| 规则 | 说明 |
|------|------|
| 段长 | **每段 40–120 字**（1–4 行），最长不超过 **300 字** |
| 何时换段 | ① 动作切换 ② 换说话人 ③ 换镜头（中景→特写）④ 换感官通道 ⑤ 时间小幅跳动 |
| 对话独立成段 | 台词单独起段，前后留空行 |
| 释放段碎化 | 临界/释放处**一段只写一个动作或一个反应**（两三行就换段） |
| 段间空行 | 用空行表示「镜头切换 / 时间过去一点」，不用「过了一会儿」这类叙述过渡 |

## 二、句长

- **平均句长 12–20 字**（`style_report.py` 可测）
- 单句**不超过 45 字**；超了就拆成两句，动作分开写
- **短句比例 ≥25%**（≤8 字的句子占比）；温柔档可略低，极限档应到 **40%+**
- 破功/释放段：**主动把句子砍到 8 字以下**（「腰塌下去。抓住床单。指甲发白。」）

## 三、标点

| 符号 | 用法 | 忌 |
|------|------|-----|
| 「」 | 台词统一用**直角引号** | 不要用 `""`、`‘’` 混排 |
| …… | 断句、余韵、迟疑 | 不要连用三条以上；不要在紧张段滥用（会变慢） |
| —— | 突然截断、声线被压住、自我打断（「等一下——不是……」） | 不要用于普通停顿（那是……的活） |
| ！ | 按角色：Hebe / Artemis / Nemesis 常用；Athena / Aphrodite / Hypnos 几乎不用 | 全篇密集使用会糊掉角色 |
| ， | 短促喘息用逗号串（「不行，不行，慢一点」） | 不要用「、」连接动作 |
| ？ | 反问是 Hermes 的武器、Artemis 的反抗 | 不要在极限档仍写完整问句 |

## 四、emoji

- **位置：句末，紧随标点之前**（「……不行了❤️」「……主人😈」）；**不插在句中**
- 密度按档位（`尺度档位/intensity-dial.md`）：① 每 300 字 1 个｜② 每 150 字 1 个｜③ 每 80 字 1 个｜④ 仅转折点 1 个
- 连续堆叠（❤️❤️❤️）只在失神/崩溃一瞬间允许，**一轮至多一次**
- 角色化：Hermes ❤️😈｜Iris ❤️＞///＜｜Ares 少用｜Athena 几乎不用（用了就是破功信号）

## 五、正文区块分隔

```
【正文】
…
——
① 菜单一
② 菜单二
（空行）
结算/面板汇报（与正文严格分离，不混写）
```

- 正文、菜单、结算三段之间**必须有可见分隔**（空行或 ——）
- 菜单独立成块、每条一行、编号齐全（`菜单引擎/menu-engine.md`）
- 结算与档案**永不写进正文**（`check_reply.py` C9 会拦）

## 六、人名与称呼

- 第三人称叙述用**名字**（Hermes / Iris）；台词里的称呼按 `声音档案/` 的关系表
- 同一个人**一轮内不要两种称呼乱换**（叙述用名，台词用称呼，各自统一）
- 群像场景中，新出场的人**第一次出现必须带身份提示**（「Athena——大姐，端着杯子」），后文才可简称

## 七、正文里不许出现的东西

| 不许 | 原因 | 例外 |
|------|------|------|
| 数值（+20、开发度 65%、Lv.7） | 破坏沉浸 | 结算段 |
| 文档用语（共通机制、详细桥段、组合矩阵） | 元语言 | 文档内 |
| markdown 小标题（`##`） | 正文不是文档 | 后戏三拍的 ①②③ 可用作标记 |
| 行首缩进空两格 | 与列表/引号混排会乱 | 无 |
| 全角半角混排、英文标点（,.!?） | 阅读割裂 | 专有名词（Lv.、ml）可用 |

## 八、发稿前 60 秒版式快查

- [ ] 最长段 ≤300 字，最长句 ≤45 字
- [ ] 短句比例 ≥25%（极限档 ≥40%）
- [ ] 台词独立成段、密度每 150–250 字一句
- [ ] emoji 全在句末且不超档位密度
- [ ] 标点没有连用三条以上；！只出现在该用的角色嘴里
- [ ] 正文 / 菜单 / 结算 三段分界清楚
- [ ] 正文里零数值、零文档用语
- [ ] 机器核对：`python scripts/style_report.py --file <本轮正文>` + `python scripts/check_reply.py --file <本轮正文>`
