# 过渡句库 + 收尾回味句库 · Transitions & Endings（🆕 2026-09-26 建）

> 两处最容易被写烂的地方：**场景切换**（「然后他们来到了……」）和**结尾**（「一切都很美好」）。
> 本文件给可直接改写的句式。收尾句往往决定整轮的回味，值得单独沉淀。

## 一、场景过渡句（用画面切，不用叙述切）

| 类型 | 写法（挑一句，改词） |
|------|-------------------|
| 时间小幅跳 | 「灯又暗了一格。」｜「茶凉透了，没人去换。」｜「窗外那块亮挪了半尺。」 |
| 换场地 | 「走廊尽头那扇门开着，里面是机油的味。」｜「她把鞋脱在门外。」 |
| 换人接手 | 「姐姐的位置换成了大姐，杯子也是新的一只。」｜「有人把她的头发从脸上拨开——不是主人。」 |
| 从日常切入情欲 | 「杯子放到托盘上的声音比平时重了一点。」｜「她系围裙的手停了半拍。」 |
| 从情欲回到日常 | 「水开了。她先去关了火。」｜「毛巾搭在她肩上，她才发现自己一直在抖。」 |
| 视角/镜头拉远 | 「屋里只剩机器的低声，和两个人的呼吸。」｜「窗外的雨已经停了。」 |

**忌**：「过了一会儿」「不久之后」「然后」——全部用画面替代（craft §8）。

## 二、临界与释放的过渡

- 进临界：「那口气一直吊着，落不下来。」｜「差一点，总是差一点。」
- 寸止后重启：「她刚松下去，一切又回来了。」
- 释放前的一拍：「很静。只有三秒。」（先静一秒再爆，效果翻倍）
- 释放后接余韵：「声音散了，人还没回来。」

## 三、收尾回味句库（余韵段的最后一句 · 决定手感）

| 手法 | 示例 | 适用 |
|------|------|------|
| **日常动作收** | 「她把被角掖好，像终于把今天收起来了。」 | ①温柔 |
| **半开玩笑收** | 「『看你表现。』床垫轻轻陷了一下。」 | ②常规（Hermes/Iris 双人） |
| **沉默收** | 「谁都没说话。机器还在低声转着。」 | ③极限 |
| **报告式收（角色化）** | 「她合上本子，罕见地什么也没记。」 | Athena 在场 |
| **赖账收** | 「『刚才那些，不算。本小姐什么都没说。』」 | Nemesis |
| **一句问句收** | 「『主人……明天，还来吗？』」 | 长线钩子 |
| **不写收（留白）** | 直接空行 → 菜单 | 需要强钩子时 |

**规则**：
1. 结尾**不要出现抽象总结**（「这一夜很漫长」「她明白了什么」）
2. 收尾句≤20 字，最好≤12 字
3. 收尾与**菜单分开**：先收尾句，再空行，再菜单
4. 连续两轮不要用同一种收尾手法（台账见 `references/文风监控/style-log.md`）

## 四、自检

- [ ] 本轮无「过了一会儿 / 不久之后 / 然后」
- [ ] 每个场景切换都有画面锚点（声音/气味/温度之一）
- [ ] 收尾句 ≤20 字、不抽象、与上轮手法不同
- [ ] 收尾句与菜单之间有可见分隔
