# 动词库 + 比喻意象库 · Verb & Image Bank（🆕 2026-09-26 建）

> 解决：动作词反复用「摸/弄/插」、比喻反复用同一个。写作时**按场景取词**，并且**一轮内不复用同一意象**。
> 配套：`craft-guide.md` §9 高频短语替换池、`references/文风监控/motif-ledger.md` 跨轮意象台账。

## 一、动作动词库（按力道分三档，同段内不重复）

| 力道 | 动词 | 适用 |
|------|------|------|
| **轻**（挑逗/铺垫） | 蹭、扫、撩、描、绕、搭、摁、捻、点、托、蹭过、拂、含在齿间 | ①温柔档、②常规前段 |
| **中**（推进） | 压、推、扣、绞、收、送、顶、掐、扯、翻、按实、扣住腰、攥住腕 | ②常规、③极限前段 |
| **重**（临界/释放） | 撞、砸、贯、撑开、楔进去、钉住、钉到底、抖开、垮、塌、绷断 | ③极限、④黑暗（需主人明令） |

**手部细分**（避免全用「摸」）：指腹、指节、指甲背、虎口、掌心、手腕内侧、掌根压。
**身体细分**：后颈、耳后、锁骨、腰窝、胯骨、膝内侧、脚踝——**写具体部位比写「敏感处」有效十倍**。

## 二、声音动词库

喘、咽、吸、抽气、噎住、闷哼、低吼、破音、失声、干哑、气音、水音、咕噜、黏响、漏出一声、咬断在喉咙里。
**机械/器具声**：低频运转、咔哒、链条绷紧、气压泄出、金属相碰、电机换档。

## 三、比喻与意象库（分场景 · 一轮只用一组）

| 场景 | 意象组 | 可用比喻方向 |
|------|--------|-------------|
| 改造间 / 机械 | 金属、齿轮、电流、液压、铁锈、机油 | 像被机器接管、像零件被拆开又装回、像电流过了一遍 |
| 寝间 / 深夜 | 棉、暖灯、被角、枕、呼吸、远处车声 | 像沉进棉花里、像被夜包住、像退潮 |
| 茶室 / 茶会 | 茶雾、瓷器、水痕、屏风、坐垫 | 像茶凉了一样慢下来、像瓷器上的一道裂 |
| 浴室 / 温泉 | 水汽、瓷砖回声、皂沫、雾面玻璃 | 像被水托住、像玻璃上的一层雾被抹开 |
| 花园 / 温室 | 藤蔓、花瓣、泥土、虫鸣、日晒 | 像被藤缠住、像花开到某个点会发抖 |
| 书房 / 纸笔 | 纸、钢笔、笔记、翻页、油灯 | 像一行字写歪了、像被翻到下一页 |
| 厨房 | 面粉、糖霜、热气、奶油 | 像糖化在手心、像锅里的水将沸 |
| 天象 / 时间 | 潮、退潮、雷雨前的闷、日出前最冷的一段 | 像浪一层压一层、像雨前空气变重 |

**规则**：
1. **一轮只用 2–3 组意象**，其中主意象 1 组（`style_report.py` 会统计，单组 >8 次即判过载）
2. 同一意象**不在相邻两轮重复**（查 `motif-ledger.md`）
3. 比喻标记（像/似/如）**一轮 ≤3 处**，其余改成直写
4. 不许出现 craft §8 的禁用词（仿佛/好像/就像……一样 的高频堆叠）

## 四、情绪外化词库（把「羞耻/快感/抗拒」写成可见动作）

| 情绪 | 外化动作（选 1–2 个，不要全上） |
|------|--------------------------------|
| 羞耻 | 别过脸、咬手背、把脸埋进枕头、耳根发烫、用手背挡眼睛、假装整理头发 |
| 抗拒 | 膝盖并拢、脚趾蜷起、抓床单、往后缩半寸、把话咬断 |
| 快感冲顶 | 腰塌、脚背绷直、喉咙发紧、手指张开又收紧、视线失焦 |
| 依赖 | 抓住衣角、往怀里蹭、追着看主人的表情、自主迎上去 |
| 破功 | 称呼变、句子碎、出声后自己愣住、捂住嘴、眼泪先出来 |
| 失神 | 翻白眼、流口水、语言停摆、身体先于意识反应 |

## 五、自检

- [ ] 一轮意象 ≤3 组、主意象 <8 次、比喻标记 ≤3 处
