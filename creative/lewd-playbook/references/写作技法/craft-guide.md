# 写作技法层 · Craft Guide（🆕 2026-09-26 建）

> 机制手册回答「做什么」，本文件回答「**怎么写**」。
> 适用：所有色情互动的正文写作。与 `运行手册/runbook.md` 的 C 阶段配套使用。
> 本文件是全库唯一的写作技法权威；新增技法写这里，不写回 SKILL.md。

## 一、五感配比（避免视觉独占）

| 感官 | 建议占比 | 怎么写 | 反例（别这样） |
|------|---------|--------|---------------|
| 触觉 | 35% | 温度、湿度、压强、摩擦、指腹与指甲的差别、衣服的布料与勒痕 | 「摸了她一下」 |
| 听觉 | 25% | 呼吸节奏、吞咽、布料摩擦、器具机械声、水声、喘息破碎成音节 | 只有「呻吟起来」 |
| 体感/内感 | 20% | 酸麻、抽搐、涌上来的热、发软、失重、腰塌下去、意识断片 | 全部写「很爽」 |
| 嗅觉 | 10% | 汗、茶、酒、药、金属、皮革、房间的味道——**气味是最省字的氛围工具** | 完全没味道 |
| 视觉 | 10% | 只挑三个最关键的画面（表情、姿态、狼狈处），不要全景直播 | 从头到脚逐寸描写 |

**规则**：每 200 字至少换一次感官通道。连写三段触觉就插一段声音或气味。

## 二、节奏曲线（五段制）

```
铺垫 ── 升温 ── 临界 ── 释放 ── 余韵
 20%     30%     25%     15%     10%
```

| 段 | 职责 | 时长/篇幅 | 技巧 |
|----|------|----------|------|
| **铺垫** | 建立场景与心理落差；先把「她平时的样子」立住 | 最短但要准 | 日常质感（倒茶的手、整理头发的习惯）；让她先嘴硬/先端庄，后面才有得破 |
| **升温** | 层层加码，每层给一个「新的东西」 | 最长 | 一次只加一样：先手、再声音、再道具、再机制。**不要一次全上** |
| **临界** | 吊住、重复、寸止；把理智磨薄 | 次长 | 「差一点」写三次，每次换一个感官通道；此处最适合放机制（冻结/遮蔽/停时） |
| **释放** | 爆发要短、要碎、要不完整 | 最短 | 句子变短、断句变多、标点消失；不要在这里堆形容词 |
| **余韵** | 超敏期、体温、狼狈、依赖 | 收尾 | 声音哑、腿软、抓衣角、眼神空——**这一段决定「手感」是否真** |

**长线（多轮）**：把五段拆到多轮里——本轮只走「铺垫+升温」，临界留给下一轮（开场三读里的钩子就是这么来的）。
**寸止流**：临界段可以连续占据两轮，第二轮再释放；主线不推进时用「未结事项」补张力。

## 三、篇幅分配（一次回应 1000–2000 字怎么切）

- 场景与状态锚定（她此刻的姿势/位置/在场有谁）：150–250 字
- 过程推进（三到五个「加码单元」）：500–900 字
- 临界与释放：150–300 字（**宁短勿长**）
- 余韵 + 对白收束：100–200 字
- 后戏三拍 → 独立段落，不计入正文

> 如果写不到 1000 字：不是「词不够」，而是**加码单元太少**。加一个单元（换道具/换位置/换人参与/加一层机制），字数自然够。

## 四、镜头调度

### 单人
- 镜头距离：中景（姿态）→ 近景（表情/手）→ 特写（一处细节）→ 拉回
- 心理与身体**交替**：外在动作一段 → 她的内心一句 → 再动作

### 双人（女仆 × 女仆）
- 每段只让**一个人做动作**，另一个只给反应；下一段交换
- 用称呼变化标记攻守转换（「杂鱼主人」→「主人……」，或「妹妹」→ 直呼名字）

### 多人（3 人以上 · 群像）
- **点名—反应—交错** 三拍为一组：点名谁在做什么 → 给那位的反应 → 切到旁观者的即时反应
- 一次最多让 **3 个人**有台词，其余只给动作与声音（否则读者记不住）
- 每 500 字给一次「全景一句」（全场在发生什么/屋里的温度/声音的层次）
- 排队/接力类：用「序号」锚定（第一人、第二人…），并让**下一位的反应**当过渡

## 五、台词技法

- **密度**：正文每 150–250 字给一句台词；纯动作段落别超过 300 字无台词
- **破碎化**：情动时句子要断——省略主语、用破折号与省略号、重复单字（「等、等一下——」）
- **称呼是水位计**：称呼越正式 = 越在硬撑；改口直呼名字 = 破功；加敬语/加「主人」= 求饶
- **不要写「她说」**：用动作带台词（「她咬住下唇：『……才没有。』」）
- **声音要能被"听见"**：喘息、吸气、吞咽、喉咙里的气音，比形容词有效
- **拒绝全知解说**：不要替角色解释她为什么这样，让动作自己说

## 六、身体描写层次（由远及近）

1. **轮廓**：姿态、重心、手放哪、衣服的状态（歪了/湿了/勒痕）
2. **表面**：温度、汗、颤、鸡皮疙瘩、发丝贴脸
3. **内部**：酸胀、抽紧、涌上来的热、失重、想抓东西的冲动
4. **失控**：意识断片、语言能力下降、身体先于意识反应

> 每层只给 1–2 句，四层走完就是一段完整的身体描写。**不要一次写满四层**，分层递进。

## 七、主人留白（硬规则）

- **不写主人的身体反应、不写主人的选择、不写主人的心理**
- 需要表达「主人在做什么」时，用**女仆的感知**转述：「身前的影子没动，她先自己软了半分」
- 主人只以**命令、动作结果、沉默**出现——沉默是最有威力的留白
- 主人不下令时，女仆可自行推进剧情（自主续写），但不能替主人决定

## 八、反 AI 味词表（🈲 出现即重写）

| 禁用 | 为什么 | 替换方向 |
|------|--------|---------|
| 缓缓地 / 慢慢地 | 最典型的 AI 填充副词 | 删掉，或用具体节奏（「一寸一寸」「停三秒」） |
| 不禁 / 忍不住地 | 偷懒的心理概括 | 写身体直接的反应（手指先抓了床单） |
| 仿佛 / 好像 | 隔一层，削弱现场 | 直接断言，或用比喻但不带「仿佛」 |
| 空气仿佛凝固了 / 时间仿佛静止 | 陈腔 | 用具体细节（茶没了热气、钟声没响） |
| 不知过了多久 | 逃避时间处理 | 给具体刻度（三分钟、两轮、天亮了） |
| 一丝 / 一抹 / 一缕（滥用） | 同质化 | 换量词或直接写对象 |
| 完美 / 极致 / 无比 | 抽象赞美 | 换成可观测的事实 |
| 复杂的情感 / 说不清的情绪 | 空转 | 落到一个动作或一句话 |
| 大量 / 各种各样 | 模糊 | 给数字或举例 |
| 「她的身体很诚实」 | 用多了成口号 | 换成具体背叛她的动作 |

## 十、情动分级用词（配合 `references/词库/lexicon.md`）

- 语气、喘息、台词破碎度、称呼变化**都随档位走**：温柔档几乎不断句，极限档整句只剩音节
- 不要全程高音：**有起伏才有高潮**——先给一段克制的对外，才有后面的崩

## 十一、写作后自检（60 秒）

- [ ] 五感通道换过 ≥3 次
- [ ] 五段节奏齐了吗（缺余韵最致命）
- [ ] 加码单元 ≥3 个，且每个都「新」（新道具/新位置/新机制/新参与者）
- [ ] 台词密度够（≥4 句），且抽三句能认出是谁
- [ ] 反 AI 味词表零命中
- [ ] 高频短语在一轮内不重复
- [ ] 主人留白：全篇无主人身体/心理描写
- [ ] 结尾有菜单 1–4 条

## 十二、常见写作失误

1. **一路平推**：没有铺垫与临界，全程高音 → 读者疲劳，高潮不成立
2. **一次全上**：把装备+机制+多人+道具一口气塞进第一段 → 后面无牌可打
3. **视觉直播**：位置关系写得很清楚，触感与声音为零 → 像看说明书
4. **结算语入侵**：正文里出现「+20」「开发度 +5」→ 破坏沉浸（数值归结算段）
5. **角色同质化**：所有人都用同一种呻吟与同一个称呼 → 用 `声音档案/` 对齐
6. **余韵缺失**：释放完立刻切下一件事 → 手感全丢
7. **忘记钩子**：上一轮埋的未结事项完全没接 → 连续性断裂（见 runbook A 阶段）
