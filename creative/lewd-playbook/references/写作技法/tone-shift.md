# 腔调转换 · 报告腔 ↔ 描写腔（🆕 2026-09-26 建）

> 风险最高的是「报告类」角色（Athena／系统／芯片播报／面板结算口吻）——她们一开口，正文很容易变成说明书。
> 规则：**报告是角色的皮，不是叙述的方式**。报告可以出现在台词里，不能出现在叙述里。

## 一、三条界线

| 位置 | 允许 | 不允许 |
|------|------|--------|
| 叙述句 | 描写、动作、感官、留白 | 数据、参数、机制名、结算语 |
| 台词 | 报告腔（Athena、系统播报、芯片提示）——这是**人设** | 报告腔变成解释剧情的旁白 |
| 结算段 | 全部数值与状态 | 混进正文 |

## 二、报告腔的正确用法（台词内）

- **短**：台词内报告不超过 20 字（「心率一百二十六。」「第三档。」）
- **被打断**：报告被快感打断才有戏（「……数据……异常……呜……」「据记录……嗯❤️」）
- **前后对照**：冷 → 断 → 乱码/术语串行 = 她的破功线（`声音档案/athena.md`）
- **不解释机制**：不要借她口说出「状态冻结会自动累积快感」这种说明书内容；用身体反应体现

## 三、把「报告腔」翻译成「描写腔」的对照表

| 报告腔（别写进叙述） | 描写腔（应该这么写） |
|--------------------|--------------------|
| 她被冻结在临界状态，快感持续累积 | 那口气一直吊着，落不下来；她越挣越多，却没一处能到 |
| 感官被遮蔽，她浑然不觉 | 她看着天花板，脸上什么也没写；身体自己在动 |
| 高潮累计三次后一次性释放 | 攒着的东西一口气砸下来——她连喘的空隙都没有 |
| 开发度上升，敏感度提高 | 昨天还只是摆设的地方，今天隔着衣服一碰，她自己先红了眼 |
| 进入了共感链同步状态 | 姐姐只是抬手捏了下自己的手腕，妹妹那边就先抖了一下 |
| 他触发了她的乳头开关 | 指腹擦过的那一下，她手里的茶杯晃了晃 |

## 四、群像里的信息密度

多人同场时，**别让任何人当解说**。需要交代状态（谁被锁着、谁没轮上）时：
- 用**动作与位置**交代：「Iris 的手还按在自己裙子上没敢动」＞「Iris 目前处于待机状态」
- 用**别人的反应**交代：「Nemesis 看见她的手腕就笑出了声」＞ 解释她被锁了
- 一轮最多一次「角色化报告」（Athena 的一条记录），多了就成文档

## 五、自检

- [ ] 叙述句里零数据、零机制名
- [ ] 报告腔只出现在台词里，且每条 ≤20 字
- [ ] 报告类角色的报告被至少打断一次（体现破功）
- [ ] 群像里没有「解说员」角色
