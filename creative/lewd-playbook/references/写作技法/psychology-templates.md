# 心理描写模板 · 羞耻 → 破功 → 依赖（🆕 2026-09-26 建）

> 原则：**心理一律外化成动作**，不写「她感到羞耻」「她意识到自己变了」。
> 三段式对应角色弧线的三个台阶，每段给：触发点 / 身体信号 / 台词走向 / 收尾。

## ① 羞耻（起点：还想维持体面）

| 要素 | 内容 |
|------|------|
| 触发 | 被看见（被看到表情、被数出次数、被公开点名） |
| 身体信号 | 耳根发烫、别过脸、咬手背、把手藏到身后、假装整理头发 |
| 台词走向 | 完整句 + 硬撑的理由（「只是……有点热」「谁、谁说的」） |
| 收尾 | 一句自己推翻自己的话（「……不许看。」） |
| 忌 | 「羞得想找个地缝钻进去」（模板化） |

## ② 破功（中点：身体先于意识反应）

| 要素 | 内容 |
|------|------|
| 触发 | 被持续施压到某个具体动作（不是笼统的「被玩到极限」） |
| 身体信号 | 抓床单、膝盖并拢又松开、腰自己迎上去、脚背绷直 |
| 台词走向 | 句子开始碎：省略主语 → 只剩称呼 → 单字 + 气音 |
| 收尾 | 出声后自己愣住（这一顿比声音本身更有戏） |
| 忌 | 一次到位（要给她 2–3 次「差一点」） |

## ③ 依赖（后点：身体记住了，人还没承认）

| 要素 | 内容 |
|------|------|
| 触发 | 结束后的空档（清理、后戏、被抱着） |
| 身体信号 | 抓住衣角、往怀里蹭、追着看主人表情、主动把手放回原位 |
| 台词走向 | 短、软、带问句（「明天……还来吗」「刚才那下，人家记住了」） |
| 收尾 | 一个**日常动作**封口（掖被角、关灯、把杯子推正） |
| 忌 | 直接表白或抒情总结；依赖必须靠动作显形 |

## 三段比例建议（一轮 1000+ 字）

- 羞耻：约 30%（铺垫期的燃料）
- 破功：约 50%（主体过程）
- 依赖：约 20%（余韵段，别省）

> 长线（多轮）时：本周走完 ①→②，把 ③ 留到下一轮开头 = 天然的连续性钩子（配合 `continuity.md`）。

## 自检

- [ ] 全篇没有「她感到/她意识到/她明白」这类心理直述
- [ ] 三段都有具体动作锚点（不是形容词）
- [ ] 破功段有 ≥2 次「差一点」
- [ ] 依赖段用日常动作收，不用抒情句
