# 长线运营手游的机制/卡池查证

主人常问「XX 游戏的卡池规则/保底/数值是什么」。这类问题**不能凭记忆答**（版本会改、测试服与正式服数字不同、社区文章互相抄袭过时数据），但也**不能只丢一堆链接**——要给结论 + 分层 + 明确来源等级。

## 触发条件

- 问某手游的卡池结构、概率、保底、继承规则、抽数奖励、武器池/命座/重复角色转化
- 问某版本活动机制、新干员/角色获取方式、限定轮换
- 要给抽卡规划建议（垫池、攒抽、是否值得抽）

## 工作流

1. **先定官方术语**。用错名词会导致查不到、也显得不专业。查一次官方公告就拿到：
   - 终末地：`寻访` 体系 = `特许寻访`（限定/UP 池）+ `基础寻访`（常驻）+ `申领`（武器池）；抽卡资源 = `嵌晶玉`、各类 `寻访凭证`、`武库配额`。
2. **找一手源（优先级从高到低）**
   1. 官网公告列表（如 `endfield.hypergryph.com/news`）→ 当期 `XX寻访说明`、`版本更新说明`
   2. 官方微信公众号文章（`mp.weixin.qq.com`，官网公告多半同步发这里，纯文本最好解析）
   3. 游戏内说明页（公告里常写「更多详情请前往游戏内查看」——社区攻略就是它的二手转写）
   4. 社区攻略（游侠/3DM/九游/心愿游戏）：只用来补概率曲线、保底次数这类官方公告不写的数字
3. **判断文章时效**。看页面「时间：」字段 + 文中是否出现正式服才有的名词：出现 `特许寻访`/`申领`/正式干员名 = 正式服；只讲 `联合寻访`/`单人UP池` = 测试期，数字可能已改。**测试期数字不能当正式服结论直接用。**
4. **交叉验证 ≥2 个独立来源**，数值对齐后才写进答案；对不齐就明说「官方未公布，社区口径为 X」。
5. **输出形态**（主人偏好，别省）：
   - 开头一句话结论（这套机制「厚道/坑」在哪）
   - 表格分层：池子分类 → 概率与保底 → 继承规则 → 抽数奖励 → 副产品
   - 结尾明确标注「哪些是官方公告原文，哪些是社区整理，游戏内说明为最终解释」
   - 给一个可操作收尾（按当前已抽次数算到保底还差多少 / 是否值得继续垫）
6. 抓取被拦截时走 `web-discovery-fallbacks`（搜狗 curl 路径 + `references/china-serp-recipes.md`）。

## 坑

- **不要把不同池子的计数混为一谈**：通常「小保底（出金计数）可继承、大保底（UP 计数）不继承且每池仅一次」，白送的免费十连往往不计入任何计数——这三条是玩家最容易被误导的地方，必须分开列。
- **不要拿 `0 抽内必出` 之类的官方话术替代数字**；官方公告一般只写奖励与轮换，概率/保底次数要从游戏内说明或社区多源确认。
- 官网 SPA 详情页 URL 猜不出来，别在 `/news/<id>` 上试错，直接找同篇公告的公众号版本。
- 社区攻略站互相抄，三家写一样不等于验证过；看它们各自的发布时间是否跨版本。
- 主人玩这游戏（有 MaaEnd 辅助），回答里给当期池名/UP 干员/结束时间这类「当下有效」信息，比泛泛的机制描述有用得多。
