# 明日方舟：终末地 — 寻访（抽卡）体系核对表（2026-10 版本实查）

来源分级：**[官方]** = 官网/官方公众号公告原文；**[社区]** = 多家攻略站一致、但非官方公布 → 用时要标注「以游戏内【干员寻访】说明为准」。

## 术语（用官方名，别用「抽卡/池子」当正式名）

| 官方名 | 含义 |
|---|---|
| 寻访 | 抽卡系统总称 |
| 特许寻访 | 限定/当期 UP 池，每版本轮换 |
| 基础寻访 | 常驻池；特许寻访的 UP 干员**不会**进入 |
| 申领（如「篆玉申领」） | 武器池 |
| 嵌晶玉 / 寻访凭证 / 加急招募 / 寻访情报书 | 抽卡资源与券 |
| 武库配额 | 抽到干员时附赠的货币，换武器/资源 |

## 当期实例 [官方]（2026-10-14 公告「万物更新」特许寻访说明，cid 8548）

- 开放：版本更新后 – **2026/11/05 11:59**（以当期公告为准，会变）
- UP 六星：**祀**；池内全部六星：祀/提弗洛斯/梨诺/余烬/黎风/艾尔黛拉/别礼/骏卫
- 消耗：`万物有灵寻访凭证`、`特许寻访凭证`、`嵌晶玉`
- **UP 干员在 3 次特许寻访结束后移出**池子，且移出后**不进基础寻访**

## 概率与保底 [社区，多源一致]

| 项 | 数值 |
|---|---|
| 六星基础概率 | 0.8%（五星约 8%） |
| 小保底（六星） | 65 抽未出后，第 66 抽起每抽 +5%，**第 80 抽必出** |
| 出六星时 UP 占比 | 约 50%（歪了给其他六星） |
| 大保底（UP） | **120 抽内必得当期 UP**，每池仅生效一次 |
| 新手池 | 前 50 抽 8 折 + 必出六星，账号终生一次 |

## 继承规则（最易被误解，必须分开讲）

| 计数 | 继承 |
|---|---|
| 小保底计数 | ✅ 可继承，常规池通用，出六星才重置 |
| 大保底计数 | ❌ 不继承，池子关闭清零，每池一次 |
| 白送的免费十连 | ❌ 不计入保底计数，也不计入累计寻访次数 |

## 抽数奖励 [官方原文]

| 累计寻访 | 奖励 |
|---|---|
| 30 次 | 10 次「加急招募」（免费十连，**必出 5 星以上**，仅本期有效，不计保底、不计累计次数） |
| 60 次 | 【寻访情报书】×1 → 下次特许寻访开启时自动转为该池专用凭证 ×10 |
| 240 次 | 该池 UP 六星【信物】×1（累计重复发放） |

## 武库配额 [官方]

六星 2000 / 五星 200 / 四星 20，用于【采购中心 - 武库交易所】。角色池与武器池通过它挂钩。

## 常见策略结论 [社区]

「30 + 120 + 30 + 120」循环：先垫 30 抽吃免费十连，提前出 UP 立即停手把剩余抽数留给下池，别死磕 120（120 是硬上限，不是目标）。
