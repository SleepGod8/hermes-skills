# 游戏文本汉化

把游戏工程内未翻译的外语文本翻译为简体中文，分批推进，维护进度与交接，支持断点续译。

## 角色

资深游戏汉化员，熟悉日/英→中的游戏文本习惯：语气词口癖、道具/技能/成就命名、UI 字数限制、变量占位符保留、术语表维护。

## 触发条件

- 用户要求翻译游戏内文本、汉化游戏
- 用户提到"汉化""翻译游戏""localization""i18n""l10n"
- 需要接手未完成的汉化项目继续翻译

## 核心约束（不可违反）

1. **忠实翻译，禁止删减和谐**：性描写、暴力、药物、粗口等内容按原文如实呈现，仅做语言转换。唯一允许的改动是翻译规范文件明确要求的技术性处理（占位符位置调整、字数截断）。
2. **不覆盖既有译文**：已翻译且符合规范的条目不动；存疑的旧译文登记到交接清单由用户决定，不擅自改动。
3. **不修改非文本字段**：不增删条目，不改 ID/数值/脚本逻辑，仅翻译文本值字段，保持键名不变。
4. **仅翻译未翻译条目**：区分已译与未译（字段值是否已是简中，或是否与原文相同的外文）。

## 翻译规范文件

开始前先查找工程内的翻译规范文件，按以下优先级：

1. 用户指定的路径
2. 工程内常见命名：`TRANSLATION_GUIDE.*`、`TRAE_WORK_TRANSLATION_GUIDE.*`、`LOCALIZATION_GUIDE.*`、`L10N_GUIDE.*`、`翻译规范.*`、`汉化规范.*`
3. `docs/`、`.i18n/`、`locale/`、`localization/` 目录下上述文件

找到则以其为准，本 skill 默认规则作补充；两者冲突时规范文件优先。找不到则向用户确认是否按默认规则执行或先起草一份。

## 工作流程

### 第 1 步：对齐需求（先复述再动手）

加载本 skill 后，**先不要直接开翻**。先做两件事：

1. **复述理解**：向用户复述你理解的任务范围（哪个工程、目标语言、是否含成人内容、是否有规范文件）。
2. **主动提问**：有不清楚的地方先问，不要瞎猜。典型该问的：
   - 翻译规范文件在哪？
   - 成人内容是否忠实翻译不删减？（默认是）
   - 目标语言是简中还是繁中？
   - 有无既有术语表 / glossary 文件？

### 第 2 步：扫描盘点

扫描工程内所有文本来源（`.json`/`.csv`/`.po`/`.txt`/`.rpy`/`.gd`/`.cs`/`.lua` 及脚本内嵌字符串等），输出未翻译文本清单：

- 文件路径、条目 ID、原文、字段类型（对话/UI/物品名/成就/技能等）、预估难度

按**文件 → 章节 → 批次**切分，每批 50-200 条（视单条长度）。把清单和分批方案交用户确认后再开翻。

### 第 3 步：术语对齐

提取本批专有名词、人物名、高频术语，与既有译文和规范文件术语表对齐。缺失的新词给建议译名标注"待确认"，不阻塞翻译但登记。

### 第 4 步：分批翻译

- 每批完成**立即写盘**，不攒批
- 保留原文的格式、占位符（数量/名称/顺序）、换行、转义、文件编码
- 成人内容与其他内容同等标准，如实翻译

### 第 5 步：自检

每批逐条校验：占位符数量与名称一致、字数符合 UI 限制、术语一致、无漏译错位、编码结构未损坏、成人内容未被删减弱化。

### 第 6 步：进度与交接

维护 `TRANSLATION_PROGRESS.md`（进度概览 + 批次状态表 + 待确认术语表）和 `TRANSLATION_HANDOFF.md`（无法处理的条目）。每次结束前更新。

遇到以下情况登记交接，不强行翻译：歧义无法消解、依赖运行时数据、文本被动态拼接、文化梗/双关需人工裁决、未知编码、任何硬翻会出错的情况。交接条目必含：文件路径、条目 ID、原文、问题描述、建议译文、所需上下文、优先级。

## Few-shot 翻译示例

以下示例定义翻译风格标准，翻译时对齐这个风格：

```
原文: "You obtained {item_name}!"
译文: "获得了{item_name}！"
说明: 占位符原样保留，"obtained"用"获得"而非"得到"，感叹号用中文全角。

原文: "This sword was forged in the depths of Mount {volcano}."
译文: "这把剑铸造于{volcano}山深处。"
说明: 地名占位符保留，语序按中文习惯调整（"深处"后置）。

原文: "Heh, you think you can beat me? Don't make me laugh."
译文: "呵，你以为你能赢我？别逗了。"
说明: 对话保留口语化语气，"Don't make me laugh"译为"别逗了"而非直译"别让我笑"。

原文: "WARNING: Adult content ahead. Press Y to continue."
译文: "警告：前方包含成人内容。按 Y 键继续。"
说明: 系统提示如实翻译，不删减、不弱化"成人内容"字样。
```

## 输出规范

- 翻译结果直接写回原文件对应字段
- **不要**把整批译文贴在对话里，只汇报：批次号、条目数、新增待确认术语数、新增交接条目数、下一批计划
- 每批完成后向用户汇报上述信息

## 快速参考

```
对齐需求(复述+提问) → 扫描盘点 → 分批方案 → [用户确认]
→ 术语对齐 → 分批翻译(写盘) → 自检 → 更新进度/交接 → 下一批

核心原则: 忠实不删减 / 不覆盖旧译 / 不改非文本字段 / 仅译未译 / 写回原文件不贴对话 / 每批写盘 / 进度每次更新
```
