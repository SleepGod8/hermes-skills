# 义体 / 芯片 / 程序 / 锁：跨会话继承的状态形状（2026-09-24 实测）

> 续 `references/panel-batch-edit-recipe.md` §E。本文只写「下一轮会话必须能原样还原的状态形状与结算口径」，不含剧情。

## 1. 义体栏（🔩）

- 槽位共 12 个：**眼 / 喉 / 舌 / 背 / 腰 / 手 / 腿 / 胸 / 男根 / 小穴 / 后庭 / 内腔（深部）**
- 胸 / 男根 / 小穴 / 后庭 = 性器官专用槽，装后该部位开发涨速 ×2（联动开发进度条）
- Athena 现装 **8 槽**（2026-09-24 状态）：
  `🌀腰槽·机械腰（腰活塞·四档自动抽插机关）｜🎤喉槽·机械喉（自动吞吐/真空/变声）｜👅舌槽·机械舌（高频振动/延长/分叉/变硬）｜🥛胸槽·承托架＋吸吮罩＋膨胀泵（泌乳线）｜🍆男根槽·全家族最大规格机械男根（炮机化）＋储液腔＋锁精环＋「反噬」词条｜🌸小穴槽·振动核心＋自动吞吐件＋储液件＋灌注件｜🌹后庭槽·扩张器 Lv.4＋自动吞吐件｜✋手槽·义手（振动指／扩张／精准力控）＋词条「遥控」「共鸣」`
- 空槽 4 个：**眼 / 背 / 腿 / 内腔**（主人续装时从这四项里点）
- 写法：`磨合度 **80%**（<已装槽数> 槽装机·<最近一次事件>后）`
- ⚠️ 写完数一遍当行枚举项再写 `N 槽`（计数与枚举不一致会被后续会话当真，踩坑见 recipe §C）
- 拆件＝空槽期（该部位敏感度反而暴涨、发痒、主动求装）；换到别人身上有不适应期（效果减半）

## 2. 磨合度：独立进度指标，**不进 EXP**

- 0–100%，部件记住宿主形状与反应的程度，越高效果越好，满磨合可自动微调
- 约定增量：**每次装机 / 换件 / 高强度使用轮 +5%**（实测轨迹 0→15→25→35→45→50→55→60→65→70→75→80）
- **不占 EXP、不改等级**；换件/拆件不改磨合度（件只认人）
- 结算时容易漏：这一轮没有 EXP 变化，但磨合度该涨 → 仍然要写进义体栏

## 3. 芯片栏（🧠）

- 插槽：**后颈主槽 ×1 ＋ 耳后副槽 ×2**；热插拔有 3 秒空白期（换卡瞬间会失神/语调错乱）
- Athena 现状（2026-09-24）：
  - 主槽 🌐**联网卡·金**（词条 遥控／共鸣 ＋「主从」＝**服务器**：可调全员敏感度倍率 0.5×–3×；每调高一人的倍率，自身负载同步骤涨；网络反噬全部汇入服务器）
  - 副槽 🎯服从卡·蓝（口令「待命」「报数」「别动」无条件执行）**＋ 程序：自激四阶·双线版**
  - 副槽 🔒高潮许可卡·紫（与炮机高潮许可锁、锁精环三重叠加）
- **程序必须落字段**，写法：`程序：自激四阶·双线版（每 5 分钟自动升档·前后双路同步·手动不下来，直到主人叫停）`
  —— 谁写的(姐姐/主人)、几阶、触发条件、解除者，缺一样下一轮就还原不出因果
- **权限关系要落字段**：谁可调谁、谁替谁吃反噬（如「服务器＝Athena，负载步涨，反噬汇入服务器」）；断网＝断网恐慌，主人可随时掐网

## 4. 锁与「释放一次即还」惯例

- Athena 三重锁：**锁精环 ＋ 炮机高潮许可锁 ＋ 高潮许可卡**（后两者＝永久改造自带的许可属性）
- 惯例：主人给许可 → **按序解三锁**（锁精环→炮机许可→许可卡）→ 释放 → **照旧把许可卡重新插回耳后**（「释放一次就要还的」）
- 面板要记：**卡在谁手里**（姐姐掌心／枕头底下）＋ 释放后是否复位；下一轮主人说「开锁」先查持有者再演
- 未解除的持久状态必须显式落字段并标「下次继承」（实测：「求欢模式未解除」——姐姐故意留着，下一轮照样是荡妇化状态）

- **磨合度、程序运行时长、撸动/进出计数都不进 EXP**——它们进义体栏/备注作为状态与数据
- 吊着不给许可的一轮：被吊者按**成功忍高潮 +30**（不是被玩到高潮）；部位统计**不变**（无释放）
