## B. 行号插入法：一次 `execute_code` 完成 30+ 处的稳定配方（两轮实测）

比「`from hermes_tools import patch` 循环」更快更可控，适合「先插新行（芯片栏/备注）再改旧值」的批量结算：

```python
p = r"C:\Users\80704\AppData\Local\hermes\skills\creative\lewd-playbook\references\面板存档\panel-records.md"
raw   = open(p, newline="", encoding="utf-8").read()   # newline="" 保原行尾
lines = raw.split("\r\n")                              # 本文件当前是 CRLF

# 1) 插入：锚点必须唯一，收集 {行索引: [新行...]}
ins = {}
for k, (anchor, note) in NOTES.items():
    hits = [i for i, l in enumerate(lines) if l.startswith("- 📊 部位统计") and anchor in l]
    if len(hits) != 1:
        print("MISMATCH", k, len(hits)); continue      # 报出来，跳过，别硬写
    ins.setdefault(hits[0], []).extend([chip_line, note])
for idx in sorted(ins, reverse=True):                  # ★ 从下往上插，索引才不错位
    lines[idx+1:idx+1] = ins[idx]
text = "\r\n".join(lines)

# 2) 替换：REPL = [(old, new), ...]，每条断言全文命中 1 次
fails = []
for old, new in REPL:
    c = text.count(old)
    if c != 1:
        fails.append((old[:50], c)); continue

print("fails:", fails)                                 # 有 fails → 下一轮只补这几条
open(p, "w", newline="", encoding="utf-8").write(text)

# 3) 同一调用里读回验证关键行 + 跑 sync（不留半成品）
```

**实测账**：第 1 轮 9/10 命中（Hebe 撞车）→ 补 1 条；第 2 轮 9/10 命中（Artemis 措辞不符）→ 补 1 条；两轮均**无脏写、无需回滚**，合计 60+ 处编辑、每次几秒。

**优点**：① 失败被显式收集（`count != 1` 只跳过不改错人）；② 一轮完成「插入新字段行 + 覆盖 EXP/部位统计/一览表」；③ 读回验证与 `sync_to_profiles.py` 可放同一次调用。

## C. 字段行计数必须自洽：`N 槽装机` vs 实际枚举（实测瑕疵）

义体栏写着「磨合度 **55%**（**7 槽**装机…）」，同一行列出的槽却只有 6 个（喉/舌/胸/男根/小穴/后庭）——**标签与枚举自相矛盾**。

- 规则：字段行里凡是 `N 槽 / N 件 / N 台` 这类计数，**写完必须数一遍当行实际枚举项**。
- 修法二选一，别留矛盾数：① 数字改成实际枚举数；② 该槽确实存在只是漏登记 → **作为真实槽位补进枚举**（本次补 `🌀腰槽·**机械腰（腰活塞·四档自动抽插机关）**`，因腰活塞本就是机械+寄生强化，理应占腰槽）。
- 面板是跨会话继承的状态源，矛盾数字会被后续会话当真 → **当场修掉，别留给下一轮**。

## D. 等级边界与「4 处同改」

- **EXP 正好等于上限即升级**：Iris `580+20=600`＝Lv.6 上限 → `叮！Lv.7 大师`，EXP 落 `0/700`；Ares `270+20+30=320` 越过 Lv.3 上限 300 → 升 Lv.4，**溢出 20 → 20/400**（与「达上限升级、余数进下一级」一致）。
- 升级必须同改 **4 处**：① 条目等级行（等级+称号+EXP）② 服装行（称号对应换装：Lv.4 绑带款、Lv.7 大师徽章·缎带、Lv.8 传奇…）③ ⚡一览表的等级/称号/EXP 单元 ④ 备注写清 `EXP a→b **升 Lv.X 称号**（溢出 n）`。
- 过程性 EXP 与被玩到高潮分开写（如 Ares `被玩到高潮+20、成功忍网络过载+30`），主人回查「为什么跨过 300」时一眼可见。

## E. 本轮新增字段的现实形态（供后续继承）

- 面板已存在 `🔩 义体栏` / `🧠 芯片栏`（各档案均有；Eos 永远不给）。芯片栏标准写法：`后颈主槽 ×1 ＋ 耳后副槽 ×2`，含型号/品质/词条/插入状态。
