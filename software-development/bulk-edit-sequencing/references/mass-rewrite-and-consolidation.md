# 目录合并 · 批量路径重写 · 索引化（2026-10-29 实战）

> 场景：一个知识库膨胀成几十本手册（本例 19 本玩法手册 / 99,938 字），要合并成少数几本并给日常入口瘦身。
> 结论先行：**合并的收益在「入口」而不是「字数」**。本次 19 本→8 本 + 索引卡，文件数 -55%，字数反而 +5%。

## 一、执行顺序（缺一步就会翻车）

| 步 | 动作 | 为什么 |
|----|------|--------|
| 1 | 整目录快照 `cp -r <root> <备份根>/<task>-before-<ts>` | 合并会 move 原文件，没快照不可回滚 |
| 2 | 建合并件：**共用总则**（一张表说清各子玩法差别）＋各分册（原 `##` 降一级） | 保住"先看总则再看分册"的读法 |
| 3 | 原件 move 到 `_legacy/<原相对路径>`，**不删** | 可回滚 + 可查原文 |
| 4 | 每册头写「原文全文见 `references/_legacy/<原路径>`」 | 唯一定位入口 |
| 5 | 全库路径重写（两遍，跳过指针行） | 见第二节 |
| 6 | 全库 link-check + 领域校验器 | 见第三节 |
| 7 | 入口索引化（一行一卡）+ 同步子档案 | 见第四节 |

**合并件的结构模板**

```markdown
# 《控制系总纲（冻结 · 时间停止 · 感官遮蔽 · 催眠）》

> 🆕 2026-10-29 合并总纲 · 原件（归档于 `references/_legacy/`）：`控制系/freeze-play.md`、…
> 原件完整保留在 `references/_legacy/`（未删，可回滚）。

## 共用总则
（一张表：各子玩法"被抹掉的是什么/身体是否照常/解除瞬间"——先讲差别再进分册）

## 分册：freeze-play.md（原文全文见 `references/_legacy/控制系/freeze-play.md`）
（原 `##` → `###`，原 `###` → `####`）
```

## 二、路径重写：两遍 + 跳过指针行

```python
BARE = {"freeze-play.md": "控制系/control-core.md", ...}
for ln in lines:
    if any(k in ln for k in ("_legacy", "分册：", "来源：", "原文见")):
        continue                      # ← 指针行原样保留，否则会自指
    for old, new in BARE.items():
        ln = ln.replace(old, new)
```

- **两遍**：先替换带目录的 `扩展玩法/x.md`，再替换裸 `x.md`。只做第一遍会漏 README/索引里的裸名（本次 57 处引用漏 3 处）。
- **踩过的坑**：第一遍 rewrite 把 `# 分册：tentacle-play.md（原文见 references/_legacy/扩展玩法/tentacle-play.md）` 里的旧路径也改掉了，四个分册的「来源」全变成同一个文件名——修法是**重写后再按源文件列表重建指针行**，不靠替换。

## 三、校验：断链 + 归档目录豁免

```python
# ① 断链检查（排除 <占位符>）
refs = set(re.findall(r"`?(references/[^\s`\)\|]+\.md)`?", text))
broken = [r for r in refs if "<" not in r and not os.path.exists(os.path.join(base, r))]
# 期望 0

# ② 领域校验器的「索引完整」检查要把 _legacy 排除
#    and not x.startswith('references/_legacy/')
```

**本次实测**：不排除归档目录时，C9 一次报 26 个 FAIL（19 个 `_legacy` + 7 个新合并件未登记）；给卡片补全 `references/` 前缀 + 排除 `_legacy` 后 → PASS。

## 四、索引化（省上下文的主力）

```markdown
## 🎴 玩法索引卡
> 日常只读这张表；要演哪一套，再开对应手册的那一节。

| 触发词 | 一句话机制 | 手册 |
|--------|-----------|------|
| 冻结／寸止／吊着不给 | 封住到达高潮的权限，解除瞬间一次爆发 | `references/控制系/control-core.md` §状态冻结 |
```

- 卡片里的路径**必须带 `references/` 前缀**，否则校验器认不到（它按 `references/…md` 正则匹配）
- 一张卡 ≤ 一行 30 字；卡不存在＝不演，需要新玩法时先建档再补卡

## 五、承诺减字之前先量（血泪）

- 我先按「合并 + 去重 + 折叠冷门」估算了 -33k 字，实际能减 **-6k**（高估 5 倍）
- 原因：看着冗余的部分多半是**模板行**（每份档案都该有的标题行）和**在用内容**；真正的重复只有三行小段
- 正确顺序：先跑体积/重复统计脚本 → 给出"可减 X–Y 字"的区间与依据 → 再动刀
- **机械"精简"（保留 n 条 bullet、n 段正文）会毁掉长桥段**：本次把一节 4,101 字压成 245 字，且该源文件**没有进 `_legacy`**（未参与合并），差点不可回滚 → 从备份恢复原样。规则：**精简前先确认存在 pristine 副本，否则先 copy 进 `_legacy/`；高使用率的章节一律不砍。**
