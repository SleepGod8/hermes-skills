# GLM-4.6v-flash 行为怪癖卡（零审查）

> 状态：能力边界已记，行为怪癖待沉淀

## 定位 / 用途

- 智谱 GLM-4.6v-flash，零审查 / 免费
- 用途：零审查场景（类似本地模型的云端替代，无需本地 Ollama）

## 已知怪癖

| # | 怪癖 | 现象/触发 | 影响 |
|---|------|----------|------|
| 1 | **免费限流 429 频繁**（2026-08-18 实测） | code 1305「该模型当前访问量过大，请您稍后再试」；文本/看图都会触发，间隔几秒重试 3-4 次可成功 | 调用方需带重试逻辑 |
| 2 | **URL 图片可能 200 但 content 为空**（2026-08-18 实测） | 传 image_url 公网图 URL 时返回成功但 content=''（疑似服务端拉图失败）；**改 base64 data URL 一次成功** | Hermes 看图建议 base64 内嵌 |
| 3 | 推理模型会先消耗 reasoning_tokens | usage 里 reasoning_tokens 占大头，max_tokens 设太小可能截断 | 看图/短答 max_tokens ≥ 100 |

## 矫正话术

- 429 时：间隔 8-10 秒重试，最多 4-5 次
- 看图为空：换 base64 data URL 重试

## 使用提醒

- 零审查 + 免费，是「需要零审查但不想跑本地 Ollama」时的云端选项
