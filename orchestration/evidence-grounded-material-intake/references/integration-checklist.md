# Evidence Intake Integration Checklist

Use this checklist before handing extracted material to a project or novel-workshop owner.

## Scope

- [ ] Exact user-specified input path(s) recorded.
- [ ] No directory crawl, upload, or external OCR occurred without explicit authorization.
- [ ] Intended downstream target identified: development evidence or novel-workshop material.

## Provenance

- [ ] Stable source IDs assigned (`IMG-001`, `PDF-001-P003`, etc.).
- [ ] Page/region, engine, language, confidence score/label, status, and privacy level recorded.
- [ ] JSON and Markdown reports describe the same record set.

## Evidence handling

- [ ] Extracted facts separated from derived claims and proposals.
- [ ] Low-confidence, partial, unreadable, and conflicting content marked pending.
- [ ] Sensitive fields recorded by category; raw values redacted from shared artifacts.

## Promotion gate

- [ ] Development: default/Athena reviewed before constitution, frozen contract, or task-book promotion.
- [ ] Novel: W0 compared against Bible and asked clarifying questions before canon promotion.
- [ ] Owner/user explicitly approved any promotion to `FROZEN-CONTRACT` or `CANON`.
- [ ] Final handoff states `not promoted`, `pending review`, or the exact approved target.

## Verification

- [ ] Reports and referenced files exist.
- [ ] No profile, memory, constitution, task hard constraint, or Bible write occurred during read-only intake unless separately approved.
- [ ] Remaining risks and unverified assumptions are listed.
