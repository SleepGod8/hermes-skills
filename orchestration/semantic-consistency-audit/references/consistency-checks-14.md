# 语义一致性 14 项检查（P0 / P1 / P2）

> 配套 `semantic-consistency-audit/SKILL.md` 第 2 步。
> 每项给：症状 → 怎么查 → 怎么修。
> 2026-10 实测案例：某人格库机械校验全 PASS，本清单查出 **14 处**（P0 4 / P1 5 / P2 5），修 17 处编辑。

## P0 — 会直接写错（优先级最高）

### 1. 自称 / 称呼打架
- **症状**：后补的「速览」规定自称 A，而正文、台词库、记录全用 B
- **查**：搜自称词（我 / 人家 / 本人）在速览、正文、声音档案、引语库的出现分布
- **修**：**以素材为准**改速览；速览旁加一条「原写法已废」的修订注（防止后人照旧版改回去）

### 2. 辈分 / 排行写反
- **症状**：把排行靠后的写成「上位 / 姐姐 / 上司」
- **查**：先读一遍权威排行表，再逐条核对「上位/下位/长辈/晚辈/上级/下属」的用法
- **修**：改正并写明「X 排第 2，不是上位」

### 3. 同一机制两套阈值
- **症状**：A 文件写「3 点＝错乱，5 点＝崩坏」，B 文件写「1 次掉点，2 次崩坏，3 次失效」
- **查**：把机制名 + 数字一起搜（`崩坏.*[0-9]` / `阈值` / `第.*次`）
- **修**：二选一 —— ⓐ 合并成一套；ⓑ 拆成**两条独立轴**（长期累计 / 单场即时），两边互相引用并注明「各计各的，不得替换」

### 4. 出现条件与个例冲突
- **症状**：通用规则说「情形 X 不会发生」，某角色却因装备/改造/血统常驻 X
- **查**：把所有「不会/从不/只在…时」类硬规则列出来，对照每个角色的常驻状态
- **修**：个例文件加「例外登记」小节（写清「为什么是例外 + 与通用规则的区别」），通用规则侧加一句指向；**不要删规则**

## P1 — 数值与时间线

### 5. 同一物件两种构成
- **症状**：「三重锁」的第三件在两处是不同物件
- **修**：指定一行**权威定义**（标 📌），旧记录按归档无损保留，加注「曾误列，以本行为准」

### 6. 同一事件两个日期
- **症状**：裁决后把日期改到 A 日，旧历史条仍写在 B 日
- **修**：旧条加注「日期为 A（裁决 ID），此处属笔误」

### 7. 状态行滞后
- **症状**：`当前状态` 段停在几轮前，实际早已推进
- **修**：补**完整时间线**（按日期列，不编号）。结论可能没变（如「锁着未解」），但过程必须最新

### 8. 数量型字段缺口
- **症状**：累积量只写「红区 / 很多」，没有数字 → 下次接不上
- **修**：补数值；确实无据可查就明确写「未建档，下次结算补记」

### 9. 钩子池 / 待办清单自相矛盾
- **症状**：「待发生」清单还挂着已经发生在「第一次」清单里的事
- **修**：移出 + 表下留修订注「已于 <日期> 发生」

## P2 — 冗余与表述

| # | 症状 | 修法 |
|---|------|------|
| 10 | 同一机制两处档位不同（3 档 vs 4 档） | 保留完整那处，另一处改成索引「完整分档见下文」 |
| 11 | 同一机制两份写法（简版/完整版）没写层级 | 加「默认走哪一个」的层级说明 |
| 12 | 两个机制重复描述同一开关 | 写明分工：「一个讲为什么会崩，一个讲崩到第几档」 |
| 13 | 同一物件在两栏重复登记（装备栏 vs 芯片栏） | 指定哪栏为准，另一栏标「仅为索引」 |
| 14 | 「自 X 起建档」与更早的历史活动记录冲突 | 改成「**统计**自 X 起」，并说明历史活动按「不追溯」规则不计入 |

## 修复顺序（不可乱）

1. 备份到工作区外 + sha256 清单
2. 逐条 patch（同脚本内打印 OK/FAIL，失败即补）
3. 面板/数值类改动 → 跑校验器（FAIL 就回改，**不许改数迁就**）
4. 镜像同步 → `--verify-only` 复核 N/N × M/M
5. 汇总报告按 P0/P1/P2 分组 + 说明归档为何不动

## 实战记录（2026-10）

- 机械层：`verify_panels.py` PASS；`sync_to_profiles.py --verify-only` 8 档案 × 84/84 一致
- 语义层：P0 4（自称/辈分/双阈值/出现条件）｜P1 5（物件构成/觉醒日期/状态滞后/累积量缺口/钩子池）｜P2 5（档位/层级/重复开关/重复登记/建档措辞）
- 修复：17 处编辑 0 失败；双验通过
- **附带收获**：审计本身会抓到「口径编号漂移」（4 次全解被写成第二/三次）→ 促使定下「时间线禁用第 N 次」的规则
