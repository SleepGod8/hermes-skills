# 新机制 / 新玩法的详细设定骨架（八节）

> 用户钦定的硬规则：**新玩法禁止一行简介入库**，必须给详细设定。
> 直接抄这份骨架，把 `<…>` 填满，再登记索引。实战验证：2026-10「自走腰·双相深榨」按此落地，一次过审并当场开演。

## 0. 命名

- 中文机制名（可带副题），要好念、可当口令（三个字内最佳）
- 一句话定位：「这是既有哪条机制的升级版 / 分支」——把新机制挂到体系上，别让它悬空

## 1. 一句话定义 + 定位

```
> 一句话：<谁，在什么条件下，身体/反应怎么变，产生什么可感知效果>
> 定位：这是「<既有机制>」的<升级/肉体版/极端形态>——<一句解释差异>
```

## 2. 分型 / 分相（把用户的两句话拆成可独立驱动的两面）

| 相 / 型 | 场景 | 具体表现 |
|--------|------|---------|
| **A 相** | <何时触发> | <动作、节奏、深浅、停顿时长> |
| **B 相** | <何时触发> | <动作、幅度、主动/被动关系> |

- 加一条**共同点**（「都不是被带着动，是 X 自己驱动」）
- 加一条**口径澄清**：两相方向相反时必须写清「A 指 …，B 指 …，不指 …」（用户原始描述常有歧义，这里是审计高发区）

## 3. 辨识度（独一无二的标记）

- 选一个**可量化描述**的外在标记（声音/温度/气味/口头禅/计数），做成 3–4 档音色或形态表
- 写一条**写作规范**：这个标记必须能被观察者数出来 / 听出来 / 量出来（否则会退化成「很爽」「很响」这种空词）
- 说明「标记变化 = 状态变化」的对应关系（读者/主角据此判断进度）

## 4. 强度分级（Ⅰ–Ⅳ）

| 档 | 名称 | 外在幅度/频率 | 本人状态 | 可感知表现 |
|----|------|--------------|---------|-----------|
| Ⅰ | <名> | <小> | <还能完整说话/报数> | <可数> |
| Ⅱ | <名> | <中> | <开始停顿> | <成拍> |
| Ⅲ | <名> | <大> | <句子被切断> | <密到分不清> |
| Ⅳ | <名> | <极限> | <只能喘 / 计数能力崩> | <整场只剩这一个效果> |

- 必写：**升档条件 / 降档条件 / 连轮上限**（上限是安全阀，不是装饰）

## 5. 阶段 / 阶（受方视角的三阶递进）

| 阶 | 名称 | 做法 | 对方的下场 |
|----|------|------|-----------|
| Ⅰ | <吞吐/轻> | <节奏均匀> | <不够彻底> |
| Ⅱ | <大摆/中> | <幅度加大> | <说不出完整句> |
| Ⅲ | <不放/极> | <到最深处不松> | <射了还得继续> |

- 阶梯顶必须配**硬时限**（「连 ≤N 次即必须松」），否则不可中断

## 6. 联动（≥6 条，逐条互锁）

| 联动对象 | 效果 |
|---------|------|
| <既有装备/改造> | <双驱动 / 互相放大> |
| <性状词条> | <反噬 / 自伤式反馈> |
| <多人机制（共感/网络）> | <节拍照抄 / 全网同步> |
| <隐蔽类玩法> | <最容易暴露的破口> |
| <数值系统（理智/耐力）> | <加速掉点的具体方式> |
| <他人的控制技> | <被强制改参数> |
| <装备槽> | <物理关停优先于一切口令> |

## 7. 各角色表现表（一人一句，不许同质化）

| 角色 | 被这样对待时 |
|------|------------|
| … | …（保留各人既有设定：体力型硬撑、毒舌型乱码、傲娇型改口、冷感型破音、睡型梦话…） |

## 8. 名场面 3–4 个（可直接开演）

每条写：**场地 + 谁在场 + 关键动作 + 一句台词 + 收尾的一句**，并标档位。
（判据：未来 agent 读到就能照着写一场，不需要再问设定）

## 9. 红线与解除（最高优先级，放最后但不可少）

1. **不等于失控**：安全词 / 摸头 / 口令「停」→ 立即降到 0；**物理关停优先于一切口令**
2. **对象边界**：对谁不自动 / 对谁必须下令才开
3. **年龄/伦理红线**：绝不触发的对象，以及「万一在附近被触发」的当场处置人
4. **连轮上限**：Ⅳ 档连 ≤2 轮、极限阶连 ≤N 次，超限强制收尾
5. **不改人物核心**：这个机制不允许改变角色的基础语癖/人格（写一句防漂移）
