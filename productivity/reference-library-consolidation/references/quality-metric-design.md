# 质量指标设计：把「口味」变成区间 + 脚本

> 库瘦完之后，第二半问题是**内容质量**。用户只会说「太杂」「色情内容太少」「台词太多了」，这些反馈必须落成可跑的指标，而不是靠记忆。
> 来源：2026-10-29 `creative/lewd-playbook` 的连环校准（三版被否：太杂 → 台词 47% 太多 → 零娇喘太少）。

## 三条设计原则

1. **分子分母都写清**，否则比率没有意义（例：台词占比 = 引号内**有语义**字数 ÷ 正文字数）
2. **区间而非单边阈值**：凡是「越多越好」的偏好，几乎都会被后续反馈推翻（台词从「≥20%」改成「15–28%」只隔一轮）
3. **脚本要能自证**：带 `--self-test`，用一段正例断言方向正确；再加一段反例证明它会 FAIL

## 本次校准出的区间（情色正文 · Ⅱ 清简档，可作模板）

| 指标 | 定义 | 区间 | 教训 |
|------|------|------|------|
| 露骨度（R4） | 具体性行为/器官/体液词 ÷ 千字 | ≥8 | 低于此＝在写设定不在写正题 |
| 机制代偿比（R5） | 机制/系统/数据词 ÷ 性行为词 | ≤1.5 | 1.7 时用户就抱怨「设定太多」 |
| 台词占比（R6） | 引号内**语义**字数 ÷ 正文 | **15–28%（甜区 18–25%）** | 10.9% 被说「旁白替她说」；47.4% 被说「台词太多了」 |
| 娇喘密度（R8） | 引号内语气音节 ÷ 千字 | 10–25 | 必须先从台词里剥离，否则台词比率虚高 |
| 动作密度（R7） | 动作动词个数 ÷ 千字 | ≥25 | 33–66 实测都合格，不是瓶颈 |

## 关键坑：分子未分离 → 比率失真

初版把「嗯／啊／呜」算进台词字数，结果：

- 加几句娇喘就能让「台词占比」达标，指标失去意义
- 真正的语义台词其实还是 10% 出头

修法：先按音节表把语气词从引号文本里**剥离**，语义台词单独计 R6，语气音节单独计 R8。两者一个「内容线」一个「呼吸线」，不能混算。

## 校准循环（照做）

```
用户：「感觉太多了」
  → 定位是哪条指标越界（跑脚本，看 R1–R8 哪项 WARN/FAIL）
  → 降一档，同时给出**反向指标**防矫枉过正
     （降台词的同时给台词下限，并加娇喘下限，避免变成纯旁白）
  → 再测，收敛后写进 SKILL.md 与范例库
  → 在范例里标注「被否掉的两版数字」，防止下次重犯
```
