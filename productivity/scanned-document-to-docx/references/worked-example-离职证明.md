- 任职：2023-07-03 至 2026-08-14，AI 应用开发工程师，2026-08-14 解除劳动关系
- 竞业限制：`☐需要/☑不需要`（**不需要**被勾选）

## 4. 生成参数（最终收敛值）
- A4；上/下 2.2cm；左/右 3.1cm
- 标题：22pt 加粗居中，`space_after = 27pt`
- 正文：宋体 14pt，两端对齐，固定行距 31.4pt，段前段后 0
- 段1：`left_indent = 0.36cm`，`first_line_indent = 0.54cm`；段2/3/4：`first_line_indent = 28pt`（2 字符）
- 勾选前行内间距：`其离职后` + 两个**全角空格** + `☐需要/☑不需要…`
- 落款：14pt 右对齐，`right_indent = 0.76cm`，公司行 `space_after = 4pt`

修正过的两处：标题 `space_after` 45pt → 27pt（整块下移 39px）；勾选框前 2 个半角空格 → 2 个全角空格（该行宽度差 31px ≈ 1 字）。

已知未修的「假差异」：原图 ink 高度比渲染大 3–6px（扫描加粗）；原图整页右移 ~17px（扫描裁切），故取对称页边距。
