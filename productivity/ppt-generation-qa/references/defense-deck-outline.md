# 答辩 PPT 14 页结构模板（按评分标准倒推设计）

> 来源：2026-08 smart-wealth 智能财富管家答辩 PPT 实战（需求文档 v4.53 评分标准）
> 通用做法：先读需求/评分文档 → 按评分权重倒推页面 → 每页一个核心观点 + 一张图/表 + 一句结论

## 评分项倒推原则

| 评分项 | 权重 | 页面策略 |
|---|---|---|
| 各功能模块 | 各 15-20% | 每个权重高的模块设专页 |
| 答辩表现 | 10% | PPT 本身质量 + 讲稿流畅 + 问答 |
| 加分项（架构/创新/效果） | 最高 +20 | 单独突出：记忆体系/置信度/降级闭环等 |

## 页面规划（14 页，5 分钟讲稿）

```
1. 封面        项目名 + 副标题 + 一句话定位 + 答辩人/团队
2. 目录        五大部分导航（01-05）
3. 背景与痛点   4 个痛点卡片（2×2）+ 底部核心诉求一句话
4. 项目定位     ❌常见误解 vs ✅正确认知 对比卡 + 关键结论
5. 系统架构     分层架构图（前端/网关/编排/组件/工具/存储 6 层条）
6. 核心模块     职责矩阵表（Agent/服务对象/能力/技术/安全等级）
7. 核心技术①   双技术并排卡（如 RAG + GraphRAG，含数据流）
8. 核心技术②   双技术并排卡（如 NL2SQL + NL2API，含安全红线）
9. 数据架构     存储组件清单（引擎/用途/细节）+ 底部记忆闭环
10. 主责模块①  流程步骤条（横向箭头）+ 分级决策表（色阶）
11. 主责模块②  流程步骤条 + 三重防线（权限/确认/校验）+ 跨模块联动
12. 架构深度    分层记忆表（短期/中期/长期/归档 + TTL + 管理）
13. 工程实践    6 卡片 2×3（Git/测试/降级/安全/文档/协作）
14. 总结展望    成果交付 + 不足反思 + 未来展望 3 卡 + 谢谢
```

## 设计规范（金融科技风，本机验证）

- 背景深蓝 `0A1628` / 卡片次深蓝 `0F1F3A` / 点缀金色 `C9A227`
- 文字：主白 `FFFFFF`、浅蓝灰 `D8E1F0`、次级灰 `8A97AC`；语义色 绿/红/黄/蓝
- 字体：Microsoft YaHei（中文安全）
- 尺寸：WIDE 13.3×7.5，页脚 页码 + 项目名 + 分隔线
- 每个模块标题左侧金色竖条（0.08w × 0.55h）+ 主标题 + 副标题
- 卡片：roundRect，rectRadius 0.05-0.06，fill 次深蓝，line 深蓝灰
